01

Smart Scraping

経産省（METI）や電力広域的運営推進機関（OCCTO）等、エネルギー政策の重要拠点を24時間365日監視。最新の資料がアップロードされた瞬間に、システムが自動的にコンテンツを取得します。

Python Playwright SQLite
02

AI Analysis Pipeline

膨大な審議会資料、議事録、スライドを NotebookLM や最新のLLMが読み込みます。数千枚の資料から「何が決まったのか」「今後の課題は何か」を瞬時に抽出。単なる要約ではない、プロ納得のインサイトを生成します。

NotebookLM API LLM Integration
03

Automated Broadcasting

生成された解析結果は自動でRSSフィードに統合され、Vercelを通じて全世界に配信。YouTube Music等のプラットフォームに即座に同期されます。画像もAIが内容に合わせて自動生成、プロクオリティのポッドキャスト環境を維持します。
