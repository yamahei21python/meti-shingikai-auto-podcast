# 第7次エネルギー基本計画を踏まえた「原子力政策の方向性と行動指針」改定案の解説

本レポートは、第7次エネルギー基本計画（2025年2月閣議決定）の基本方針に基づき、総合資源エネルギー調査会 原子力小委員会（第49回）で取りまとめられた「今後の原子力政策の方向性と行動指針」の改定案について、その核心を整理したものである。特に、事業予見性の確保が急務となっている電力事業者およびサプライヤーに向け、地政学的リスクへの対応と長期的な供給力確保の観点から分析を行う。

### 1. ポッドキャスト解説ガイド（内容のポイント）

近年の地政学的リスクの高まりや、DX・GXの進展に伴う電力需要の急増は、日本のエネルギー安全保障に深刻な影を落としている。今回の行動指針改定は、原子力を特定の電源に依存しないバランスの良いエネルギー構成の柱として再定義し、2040年以降に懸念される「供給力の壁」を打破するための実効的な実行計画へと進化した。以下に業界関係者が注視すべき4つのポイントを挙げる。

*   **原子力発電の見通しと建て替えの必要性**
    2040年以降の急激な供給力低下を防ぐため、具体的な必要容量が明示された。試算では2040年代までに約220万～550万kW（約2～5基）、2050年代までに計約1,270万～1,600万kW（約11～14基）の建て替えが必要とされる。これは大型炉（1基120万kW）をベースとした算出であり、SMR（1基30万kW）で換算した場合、大型炉1基に対し4基分が必要となる。この大規模な新増設・リプレースの見通しは、投資回収の予見性を高めるための国家的なシグナルである。

*   **行動指針の構造的刷新と「大前提」の定義**
    従来の「再稼働への総力結集」という柱が「原子力を長期的に活用していく上での大前提」へと昇華された。これは再稼働の進展を受け、今後の長期活用には「不断の安全性向上」や「立地地域との共生」が欠かせない恒常的な基盤であるとの認識に基づく。単なる稼働促進ではなく、社会的な信頼に根ざした持続的活用のフェーズへの移行を意味している。

*   **事業環境整備とサプライチェーンの統合的な維持**
    「事業環境整備」が独立した柱へと再編され、人材・サプライチェーンの維持・強化が盛り込まれた。特筆すべきは、官民による海外プロジェクトへの参画支援である。これは国内建設の本格化までに生じる空白期間において、海外市場での機会創出を通じて国内の産業基盤・技術を維持・継承させるという戦略的な意図を含んでいる。

*   **バックエンドプロセスと国際連携の強化**
    核燃料サイクルの安定稼働に向け、六ヶ所再処理工場の竣工と保障措置体制の抜本的強化が打ち出された。国際的な信頼を確保しプルトニウム管理を厳格化するため、独立行政法人の設置を検討する。また、仏国オラノ社の知見を活かしたMOX粉末の再利用や、同志国とのサプライチェーン共同構築など、国際連携を軸とした課題解決が図られている。

### 2. 主要な議題

原子力小委員会において、指針の具体化に向け議論された主要な論点は以下の通りである。

*   **2040年以降の「供給力の壁」への対応**
    第7次エネルギー基本計画が掲げる「特定の電源に依存しない」方針を具現化する上で、2040年以降の設備容量不足に対する危機感が共有された。民間事業者が巨額の投資を決断できるよう、国が責任を持って目標年度ごとの必要容量をロードマップ形式で明示し、地政学的リスクに晒されない強靭な供給体制を構築する必要性が論じられた。

*   **運用高度化による既設炉の最大限活用**
    既設炉の信頼性と設備利用率を向上させるための技術的・規制的論点が深掘りされた。PWRの15ヶ月運転導入に留まらず、18〜24ヶ月というさらなる長期サイクルへの移行、オンラインメンテナンス（運転中保全）の拡大、蒸気発生器等の大型機器更新による信頼性向上が議論の焦点となった。

*   **次世代革新炉の社会実装と研究開発基盤の強化**
    「次世代革新炉開発ロードマップ」の実行性を担保するため、JAEA（日本原子力研究開発機構）の機能強化や、NEDOを念頭に置いた民間主体への資金供給機能が議論された。特に、規制当局との対話を通じた許認可の予見性向上や、スタートアップを含む多様な主体が参画できる環境整備の重要性が強調された。

*   **福島復興と安全性向上への不断の取り組み**
    エネルギー政策の原点が福島復興にあることを再確認した上で、基準地震動策定時のデータ選定不適切事案等の反省から、業界全体の品質保証活動の改善が求められた。また、能登半島地震等の経験を反映し、自然災害と原子力災害が同時に発生する「複合災害」を想定した防災対策の強化が議論された。

### 3. 決定事項

第49回原子力小委員会において合意・決定された主要事項は以下の通りである。

1.  **行動指針の6つの柱と「原子力発電の見通し・将来像」の前置**
    指針の基本構造を維持しつつ、全項目に関わる「見通し・将来像」を冒頭に配置することを決定した。2040年代・2050年代の建て替え必要量を明記し、長期的投資の指針とする。

2.  **既設炉の最大限活用と再稼働加速の統合**
    「再稼働への総力結集」を「大前提」の柱へ、「再稼働の加速」を「既設炉の最大限活用」の柱へと整理・統合した。デジタル・AIによる審査プロセスの管理高度化や、運転延長認可制度の着実な執行を盛り込むことが決定された。

3.  **次世代革新炉開発ロードマップの策定とメンテナンス**
    2026年4月8日に公表された「次世代革新炉開発ロードマップ」を指針に反映することを決定した。人材・サプライチェーンの状況変化を注視し、継続的なロードマップのメンテナンスを行う方針が固められた。

4.  **核燃料サイクル安定稼働に向けた保障措置体制の強化**
    六ヶ所再処理工場等の国際的信頼を得るため、保障措置に対応する独立行政法人の設置を含む体制強化を決定した。また、仏国の経験に学び、加工工程で生じるMOX粉末を再処理工程へ戻して再利用する仕組みの導入検討を推進する。

### 4. 今後のタイムライン

本指針の実行に向けたマイルストーンは以下の通り整理される。

1.  **GX戦略地域制度の運用開始と地域選定**
    2025年8月に制度を創設。2026年4月24日に「有望地域」を決定し、同年夏頃に脱炭素電源を活用した産業クラスター創出のための地域を最終決定する予定である。

2.  **JAEAにおける研究・支援体制の刷新**
    2026年4月（令和8年4月）、JAEA内に「軽水炉工学研究センター」を新設する。リスク情報を活用したグレーデッドアプローチの適用拡大等を牽引し、規制基準の技術的検討を行う体制を本格稼働させる。

3.  **次世代革新炉の社会実装に向けた投資判断時期**
    2040年代の運転開始を実現するためには、2020年代後半が投資決定のクリティカルパスとなる。この時期までに脱炭素電源投資支援制度の具体化や、許認可の予見性向上に向けた規制当局との対話環境を整備する。

4.  **原子力小委員会の改定プロセス**
    2025年6月（第45回）から2026年6月（第49回）にかけて累次の議論を行い、第7次エネルギー基本計画の理念を具体的なアクションへと落とし込んだ本改定案を取りまとめた。
