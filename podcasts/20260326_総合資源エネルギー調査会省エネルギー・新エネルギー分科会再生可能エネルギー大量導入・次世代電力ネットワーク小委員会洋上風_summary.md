# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
第43回合同会議では、再エネ海域利用法の改正（令和8年4月1日施行）に伴う「促進区域指定ガイドライン」および「セントラル方式運用方針」の改訂が議論の柱となりました。今回の改正は、環境調査の国主導化（セントラル方式の拡充）やEEZへの適用拡大、さらには航路離隔距離の厳格な要件化など、実務への影響が極めて大きい変更を含んでいます。専門アナリストの視点から、事業者が着目すべき重要ポイントを以下に整理します。

*   **環境大臣による調査制度の導入とアセス手続の合理化**
    改正法に基づき、促進区域の指定前に環境大臣が海洋環境等調査を実施する仕組みが構築されました。特筆すべきは、国が先行して調査を行うことで、事業者が通常実施する環境影響評価法（アセス法）に基づく「配慮書・方法書手続」が一部適用除外となる点です。これにより、複数事業者によるアセス重複や地域住民の混乱を避け、案件形成の迅速化が期待されます。

*   **航路との離隔距離ルールの明確化と「ストッパー」機能の強化**
    2026年（令和8年）3月24日付の事務連絡に基づき、一般海域における風車と船舶航路の離隔距離確保の考え方が明文化されました。自由航行が原則の一般海域において、関係海運団体等の意向確認が必須となり、合意に至らない場合は有望区域への整理を見送るという強力な拒絶要件（ストッパー機能）が組み込まれた点は、実務上の大きな留意点です。

*   **事業性判断指標の高度化と具体的な数値基準の導入**
    有望区域の整理段階において、客観的な参考指標を用いたスクリーニングが導入されました。平均風速7m/s以上（高度140m）、着床式では水深50～60m以内といった具体的な閾値に加え、陸上自営線距離（最大60kmまで）を含む1～4等のスコアリング評価が設定されました。これにより、早期段階で「一定の事業性が見込めない」と判断された区域は改善策の検討対象に回されるなど、案件形成の予見性が高まります。

*   **五島洋上ウィンドファームの商用運転開始の意義**
    国内初の商用浮体式プロジェクトである長崎県五島市沖の案件が、2026年に商用運転を開始したことが報告されました。これは日本の洋上風力が「実証フェーズ」から「商用実装フェーズ」へ完全に移行したことを意味します。浮体式技術の社会実装に向けた実地データが得られることで、今後の商用化拡大に向けた技術的・経済的指針となります。

### 2. 主要な議題
*   **促進区域指定ガイドライン等の改訂案とEEZへの適用拡大**
    法改正に伴い、領海・内水だけでなく排他的経済水域（EEZ）への適用拡大を見据えた手続の整理が議論されました。EEZにおいては、経産大臣による「募集区域の指定」や「事業者への仮の地位（仮許可）の付与」といった領海内とは異なる新たなステップが導入される点について、ガイドライン改訂の方向性が示されました。

*   **海洋環境等調査の新運用とJOGMECサイト調査との連携**
    環境大臣が実施する海洋環境等調査と、JOGMEC（エネルギー・金属鉱物資源機構）が実施する風況・海底地盤等のサイト調査をいかに有機的に連携させるかが論点となりました。また、既存のアセスメント手続との「棲み分け」を明確にし、事業者の事後的負担を軽減しつつ、地域の環境保全を両立させる具体的な手順が検討されました。

*   **区域整理における事業性確保の見込み確認の厳格化**
    国民負担の抑制と洋上風力の導入拡大を両立するため、有望区域への整理段階で「事業性確保の見込み」をより厳格に評価する方針が示されました。これまでの抽象的な判断から、NeoWins（洋上風況マップ）等のデータを活用した詳細な数値指標（風速、水深、系統距離）による多角的な評価へと高度化させる点について議論が行われました。

### 3. 決定事項
1. **海洋環境等調査の新設と法定手順の確定**
    促進区域指定の法定手続に「海洋環境等に関する調査」を正式に新設しました。環境大臣が地域の特性（眺望、鳥類、ウミガメ等）を勘案した「調査方法書」を作成・公表し、その調査結果を経済産業大臣および国土交通大臣に通知・公表する一連のフローが確定しました。

2. **一般海域における離隔距離確保の拒絶要件化**
    有望区域の整理において、関係海運団体および海運事業者の意向確認を必須化することが決定されました。協議会を通じて発電事業の実施に向けた議論が整わない場合は、有望区域への整理そのものを行わない方針が明文化され、航行安全の確保が案件形成の前提条件であることを明確にしました。

3. **事業性評価のための多角的スコアリング指標の導入**
    有望区域の整理段階で参照する以下の参考指標（1～4等評価）が設定されました。
    ・風況：年平均風速8.5m/s以上を「1等」とし、7.0m/s未満は原則対象外または要精査。
    ・水深：15～30mを「1等」とし、15m未満は「要精査」。
    ・自営線距離：10km未満を「1等」とし、60km以上は評価対象外。
    これらは、有望区域への整理段階での重要なスクリーニング機能として運用されます。

### 4. 今後のタイムライン
1. **パブリックコメントの実施**
    本合同会議で承認されたガイドライン改訂案および運用方針改訂案に対し、直ちにパブリックコメントを実施します。広く国民や業界関係者の意見を募集し、その結果を考慮した上で確定版の策定を目指します。

2. **改正再エネ海域利用法の施行（令和8年4月1日）**
    令和7年6月に成立した「再生可能エネルギー海域利用法の一部を改正する法律」は、令和8年4月1日に施行される予定です。今回のガイドライン改訂はこの施行日に合わせて適用されることが前提となります。

3. **確定版ガイドラインに基づく新たな区域整理の開始**
    パブリックコメントを経て策定される確定版ガイドラインは、令和8年度以降に実施される新たな区域整理（準備区域・有望区域の選定）および指定手続において全面的に適用されます。これにより、セントラル方式に基づいた新制度下での案件形成が本格化します。
