# カスタムレポート

### 1. ポッドキャスト解説ガイド

* **クリーン燃料証書制度の核心**
本制度の核心は次世代燃料から環境価値を分離しブックアンドクレーム方式と属性取引を組み合わせて移転する枠組みにあります。具体的には燃料の原料転換という価値をMJ単位で扱う属性取引とサプライチェーン全体の削減量をtCO2単位で扱う排出削減効果取引の二段構えが示されました。属性の購入者は自ら燃料を利用していることが前提となり、削減効果の購入者は自社の排出量を控除できるという、需要家の属性に応じた柔軟な制度設計が特徴です。

* **燃料種ごとの証書化の可否判断**
ドロップイン性の高さや課税制度との整合性および需要家のニーズに基づき燃料種の選別が行われました。eガソリンやSAFならびにHVOや合成メタンなどは既存インフラへの影響が軽微なドロップイン燃料として証書化可能と判断されました。一方でバイオエタノールやFAMEなどは車両への混合制限や酸化安定性に伴う貯蔵期限の制約および複雑な税務処理といった社会実装上の課題から当面の検討を保留とする結論に至りました。

* **供給体制の柔軟性と環境価値移転**
物理的なサプライチェーンに縛られない環境価値の移転により全国各地の拠点への柔軟な供給が可能となります。ENEOSによる実証では成田空港で供給されたSAFの現物から環境価値を切り離し富士山静岡空港などの異なる拠点でその価値を宣言できることが確認されました。これにより専用タンクや船舶などの大規模な新規インフラ投資を抑制しつつ、既存の物流網を活用して迅速に次世代燃料の導入を拡大できるメリットが示されています。

* **段階的な導入ロードマップ**
制度の社会実装は3段階で計画されています。2025年度の準備期間を経て2026年度に第1段階の実証を開始し同年度末までに本格稼働の是非を判断します。第2段階の本格稼働では全ての次世代燃料を対象に事業者間の相対取引を可能とし、将来的には第3段階として取引所取引の導入や海外制度との連携といった拡張を目指す道筋が策定されました。

### 2. 主要な議題

* **クリーン燃料証書制度の具体的な設計**
地理的な範囲の考え方や属性と排出削減効果の使い分けが議論の焦点となりました。海外から日本までのサプライチェーンにおいては日本のNDCへの寄与を確実に担保し二重計上を防止する観点から燃料現物の調達を必須とする方針が示されました。ブックアンドクレーム方式による柔軟な環境価値の分離と移転は日本国内に到達した後の流通範囲に限定して適用されるという規制上の詳細が整理されました。

* **国産SAF普及における物流および供給インフラのコスト課題**
SAFの現物を全国の空港に届けるための専用インフラ構築に要する莫大なコストが課題として共有されました。ENEOSの報告では物理的な配送を最小限に留めるブックアンドクレーム方式の有効性が強調されました。既存のジェット燃料流通網を維持しながら環境価値のみを証書で移転する手法はインフラ投資コストを大幅に削減し、地方空港を含む日本全体での脱炭素化を加速させる現実的な解決策として位置づけられました。

* **次年度以降の検討の方向性**
2025年度に向けた運営体制の構築や具体的な規程類の整備が議論されました。特にレジストリによるトレーサビリティの確保策や民間各社がシステムを独自保有する場合の共通基準の策定が急務とされています。またSHK制度やGX排出量取引制度といった国内の既存制度との整合性を図り、需要家が証書を活用して法的な排出報告に利用できる環境を整えるための具体的な準備事項が示されました。

### 3. 決定事項

1. **証書化を進めるべき燃料種の特定**
物理的性質や品格法などの制度面および需要調査の結果を踏まえeガソリンやSAFならびにHVOと合成メタンおよびバイオガスを証書化対象として特定しました。これらはドロップイン燃料として既存の車両や設備にそのまま使用できるため、物理的な制約を克服するブックアンドクレーム方式との親和性が極めて高いと評価されました。

2. **バイオエタノールおよびFAMEの検討保留**
バイオエタノールはガソリンスタンドでのBtoC販売において一般消費者に環境価値の分離を説明することが困難である点やE3超の混合による誤給油リスクが懸念されました。またFAMEは酸化安定性の課題から製造後1ヶ月以内の使用が推奨される点や軽油引取税の取り扱いが複雑であるといった性質および制度上の課題があるため状況に変化があるまで検討を保留することが決定されました。

3. **クリーン燃料証書制度の3段階発展ステップの策定**
制度の立ち上げを段階的に進める方針が合意されました。2025年度の運営規程等整備を経て2026年度にサンプルを活用した第1段階の実証を実施します。その後2026年度末に本格稼働の是非を判断し2027年度以降に事業者間取引を開始する第2段階、さらにその後の第3段階で取引所取引や海外展開へと拡大させる計画です。

4. **SAF供給における実証条件の適用**
ENEOSによる実証結果に基づき当面は国内限定の環境価値移転および同一の供給事業者内での移転という条件を設ける方針が示されました。これは欧州の柔軟性制度を参考にしつつも国産SAFの普及を優先的に促進し、かつデータの信頼性とトレーサビリティを確実に担保するための戦略的な制度設計です。

### 4. 今後のタイムライン

1. **2025年度の準備期間**
2026年度の実証開始に向けて運営体制の構築や事務局機能の確立およびレジストリシステムの検討を進めます。証書の発行や移転に関する具体的な規程類の整備と関係者間でのオペレーションフローの確認を集中的に行う期間となります。

2. **2026年度末を目途とした本格稼働の是非検討**
第1段階の実証成果を検証するとともに国際的な算定ルールであるGHGプロトコルの改定状況を注視します。国際的な不確実性要因を精査した上で2026年度末までに第2段階としての本格稼働へ移行するかどうかの最終判断を実施します。

3. **2027年度以降の拡張および発展フェーズ**
本格稼働後の市場の成熟度を見極めながら取引所取引やマッチングアルゴリズムの導入を検討します。また海外制度との接続性を強化し燃料と証書を組み合わせたモデルの国際訴求や対象燃料のさらなる拡大といった制度の拡張余地について順次検討を開始する予定です。

4. **国内既存制度との連携時期**
SHK制度やGX排出量取引制度およびJクレジット制度等との整合性を確保するための方法論の整理を継続します。需要家が証書を算定に利用できるよう各制度のアップデート時期に合わせた連携を模索し社会全体でのカーボンニュートラル実現に向けた基盤を構築します。
