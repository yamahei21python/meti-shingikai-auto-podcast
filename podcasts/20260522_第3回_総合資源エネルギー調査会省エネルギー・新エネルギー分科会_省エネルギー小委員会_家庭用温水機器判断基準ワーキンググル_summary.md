# カスタムレポート：家庭用温水機器の省エネルギー・非化石エネルギー転換に向けた新制度の全容と戦略的示唆

## 1. ポッドキャスト解説ガイド（内容のポイント）

家庭部門の脱炭素化において、エネルギー消費の約3割を占める給湯分野の改革はGX（グリーントランスフォーメーション）実現の鍵となります。本制度は、従来の機器単体のエネルギー消費効率（単体効率）の向上のみならず、エネルギー種を横断した「非化石エネルギー転換」へとパラダイムシフトを図るものです。第3回判断基準ワーキンググループ（WG）の取りまとめ案に基づき、実務上の重要ポイントを解説します。

*   **脱炭素化に向けた給湯分野の重要性と制度のパラダイムシフト**
    家庭部門の最終エネルギー消費の約15％、そのうち給湯分野は約30％に上ります。新制度では、製造・輸入事業者が自ら目標を設定し達成を目指す「トップランナー制度」の枠組みを維持しつつ、化石エネルギー消費量の削減を直接的な指標とすることで、非化石転換を強力に加速させます。
*   **「定性的・定量的」目安の設定と高効率機推奨の三要件**
    高効率給湯器（ヒートポンプ給湯機、燃料電池、ハイブリッド給湯機）の普及を促すため、「定性的目安」として以下の三要件をすべて満たす環境での導入が定義されました。
    1.  **気候特性**：機器のエネルギー効率が十分に発揮される地域。
    2.  **設置空間**：戸建住宅（新築・既築）または新築集合住宅。
    3.  **経済合理性**：導入コストに見合う給湯需要が見込まれる世帯。
    これに基づき、目標年度（2034年度）の「定量的目安」として、5,605MJ/台・人という具体的な数値基準が設定されました。
*   **「追い焚き」負荷算定の導入と評価の平等性**
    実態に即した評価を行うため、従来除外されていた「追い焚き」負荷を算定に含めます。追い焚き機能のない機器については、同様の目的で行われる「差し湯」負荷を計上することで、機能の有無にかかわらず機器間の「平等な評価」を担保しつつ、利用実態をより正確に反映させます。
*   **官民一体となった普及促進の加速**
    2026年5月19日、JGKA（一般社団法人日本ガス石油機器工業会）を中心に「スマいる給湯プロジェクト（ガス石油省エネ給湯機普及促進会議）」が設立されました。また、普及の物理的障壁であったドレン排水処理について、JGKAや環境省の働きかけにより、2026年2月時点で79の地方公共団体が「雨水処理」への変更を公表するなど、設置環境の整備が急速に進んでいます。

## 2. 主要な議題

*   **国が示す定量的目安の妥当性と感度分析**
    2034年度の定量目安算出にあたり、導入割合に影響を与える変数を用いた感度分析が実施されました。
    *   **高位ケース**：戸建住宅の土地面積49㎡以下を除外、新築集合住宅の3人以上世帯の40％を導入困難とした場合、高効率機の導入割合は**41.2%**まで上昇。
    *   **低位ケース**：戸建住宅の土地面積99㎡以下を除外、新築集合住宅の導入シェアを現状維持とした場合、高効率機の導入割合は**36.6%**まで低下。
    この感度分析の結果（36.6%〜41.2%のレンジ）を踏まえ、ベースケースとしての39.3%（定量目安5,605MJ/台・人）の妥当性が確認されました。
*   **消費者向け表示事項の「予見性」と「実態」の両立**
    製造事業者には、目標年度までの開発・投資を安定させるための「算定方法の固定による予見性」が不可欠です。一方で消費者には「利用実態に近い情報」を提供する必要があります。この相反するニーズを調整するため、化石エネルギー消費量をベースとしつつ、具体的な表示方法については2031年度末までに検討を完了させる方針です。
*   **エネルギー消費効率の測定規格の構造的整理**
    機器種別ごとに適用されるJIS規格および測定・算定ルールが明確化されました。
    *   **ガス燃焼温水機器**：JIS S2075（モード熱効率）、JIS S2109（定格熱効率：暖房機能付き）。
    *   **家庭用燃料電池**：JIS C8852 附属書B。建築研究所の技術情報を活用。
    *   **ヒートポンプ温水機器**：JIS C9220（年間給湯保温効率/年間給湯効率）。
    *   **ハイブリッド温水機器**：JIS C9220に基づくヒートポンプ基準加熱効率および補助熱源機の給湯モード熱効率。

## 3. 決定事項

1.  **目標年度および定量的目安の確定と削減インパクト**
    目標年度を**2034年度**とし、定量的目安を**5,605MJ/台・人**に決定しました。本基準を達成することで、2034年度以降、現状維持（2023年度実績水準）と比較して、化石エネルギー消費量は**約104PJ**、CO2排出量は**約547万t-CO2**削減される試算となり、制度の正当性と脱炭素への寄与度が裏付けられました。
2.  **算定範囲の厳格化と除外事項**
    実態即応の観点から「追い焚き」負荷を算定に算入することを決定しました。ただし、**「暖房」に要するエネルギーについては引き続き算定対象外**とすることを再確認しました。これにより、純粋な給湯性能を軸とした製品比較が可能となります。
3.  **製造事業者等の義務と公表スキーム**
    製造・輸入事業者は、定性的目安を踏まえた「取組方針（環境別の出荷目途、普及拡大施策等）」の策定と、自らの「目標基準値」の設定が義務付けられます。これらは、資料1-2の別添様式に基づき、**2027年度中（2028年3月末まで）**にインターネット等を通じて公表する必要があります。

## 4. 今後のタイムライン

1.  **判断基準告示の公布・施行**
    2026年5月22日の第3回判断基準WGの取りまとめを受け、速やかに新制度の判断基準告示が公布・施行されます。これにより、新たな法的枠組みが正式にスタートします。
2.  **取組方針および目標基準値の公表期限**
    各事業者は、自らのポートフォリオを精査し、**2027年度末（2028年3月末）**までに取組方針と目標基準値を公表しなければなりません。特に設置制約の多い新築集合住宅等における製品戦略の再考が、この時期までに求められることになります。
3.  **表示内容の確定と目標達成の評価**
    表示事項の詳細検討を2031年度末までに完了させた後、表示準備期間を経て、目標年度である2034年度に向けて表示が実施されます。目標年度終了後には、国による実績報告の徴収と目標達成判定が行われる長期的な管理サイクルへと移行します。
