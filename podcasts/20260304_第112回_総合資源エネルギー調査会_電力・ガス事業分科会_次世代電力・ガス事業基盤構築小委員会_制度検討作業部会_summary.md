# 長期脱炭素電源オークション制度変更の核心：第112回制度検討作業部会分析レポート

### 1. 2026年度（第4回）入札に向けた政策的背景と論点
2026年3月4日に開催された第112回制度検討作業部会では、長期脱炭素電源オークションの第4回入札に向けた重要な制度変更の方向性が整理された。今回の議論の核心は、電力システム全体の「安定供給」と「経済安全保障」、そして「脱炭素化」の三要素を、いかに高度な次元で調和させるかにある。シニア・エネルギーアナリストの視点から、特に注目すべき重要ポイントを以下に詳述する。

*   **LNG専焼火力の役割再定義と供給力不足（1,300万kW）への対応**
    第7次エネルギー基本計画の検討においても、LNG火力は脱炭素化へのトランジションを支え、需給両面の不確実性に備える不可欠な「安定化電源」と位置付けられている。広域機関の最新報告によれば、2040年度に電力需要が1.1兆kWhに拡大するシナリオでは、3,900万kWに及ぶ経年火力をすべてリプレースしたとしても、なお**1,300万kWの供給力不足**が生じると試算された。この予断を許さない需給逼迫リスクを回避するため、第4回入札以降も当面、LNG専焼火力の募集を継続することが不可欠となっている。
*   **経済安保推進法との連動による蓄電池サプライチェーンの強靭化**
    蓄電池の導入拡大に伴い、特定国メーカーへの過度な依存がサプライチェーン途絶リスクとして顕在化している。これに対応するため、第4回入札より、経済安保推進法に基づく**「供給確保計画」の認定**を受けたメーカー（国内外の子会社・孫会社を含む）のセルを使用する案件を優先的に約定させる仕組みが導入される。これにより、第3回で暫定的に導入された「セル製造国30％制限ルール」はリチウムイオン蓄電池については廃止され、より実効性の高い「企業単位の認定制度」へと移行する。
*   **サイバーセキュリティ要件の厳格化（JC-STAR ★1の導入）**
    電源の分散化が進む中、サイバー攻撃に対する防護は重要課題である。第4回入札より、蓄電池および太陽光・風力のPCS等において、情報処理推進機構（IPA）が運用する**JC-STARラベリング制度の「★1（スター1）」**以上の取得が新たな要件として課せられる。
*   **水素・アンモニア案件の「低炭素化」と事前審査の迅速化**
    第4回入札から、水素・アンモニア案件には従来のグレーから「低炭素」であることを求める方針が打ち出された。審査の煩雑さを避けるため、水素社会推進法に基づく「価格差に着目した支援制度」の予備審査をオークションの事前審査として活用し、**チェックリスト方式**によって迅速に基準適合を判断する設計となっている。

### 2. 主要な検討議題と分析
本会合において、詳細設計の合意形成に向け審議された主要議題は以下の通りである。

*   **LNG専焼火力の適切な募集規模の策定**
    将来の需要増加に対応するため、2026年度（第4回）以降の追加募集を継続する方向で整理された。具体的な募集量については、2025年度オークションの結果や脱炭素電源の導入進捗を精査し、次回以降の会合で確定させる必要がある。なお、応札事業者には引き続き「2050年カーボンニュートラル」を前提としたロードマップの公表が求められる。
*   **蓄電池の約定方法の見直しと事業規律の強化**
    優先約定枠の導入とともに、落札後の計画断念（市場退出）を防ぐためのペナルティ引き上げや保証金の設定についても検討が継続されている。安易な応札を抑制し、実現可能性の高い案件を選別する規律が強化される見通しである。
*   **他市場収益監視における実効性と透明性の確保**
    電力・ガス取引監視等委員会（電取委）からの建議に基づき、相対契約に対する規律の例外対応が焦点となった。特に、市場参加に伴う手数料相当（非化石価値取引売買手数料等を想定した**0.001円/kWh程度**）を平均価格から割り引いて相対契約価格を算定することを容認するなど、実務に即した柔軟な監視運用が示されている。

### 3. 制度設計の枠組み（方向性の確認）
本会合において、以下の制度変更の方向性が事実上固まった。

1.  **LNG専焼枠の継続とトランジションの促進**
    2026年度（第4回）以降もLNG専焼火力の募集を当面継続する。これにより、電源の脱炭素化ロードマップと安定供給の維持を両立させる投資シグナルを市場に維持する。
2.  **蓄電池サプライチェーン規律の高度化**
    「特定国制限」から「経済安保推進法認定メーカー優先」への転換を決定。これにより、国内基盤の拡充に寄与する事業者を政策的に優遇する。
3.  **他市場収益監視ガイドラインの改定**
    電取委の建議通り、ガイドラインを改定する。監視の効率化を図るため、可変費の監視においては燃料費を含め**金額の大きい順に上位約9割**に達する費目を精査対象とする手法を正式に採用。また、小売部門を持たない落札事業者の不利益を解消するため、「内外無差別規律」の評価項目から社内取引特有の項目を除外する等の調整が行われる。

### 4. 今後の戦略的タイムライン
事業者は以下のマイルストーンを注視し、案件形成を加速させる必要がある。

1.  **第3回入札結果の公表と監視（2026年Q1～Q2）**
    2026年1月に実施された第3回応札について、現在電取委による価格監視が進行中。この結果は第4回以降の募集量決定の重要なリファレンスとなる。
2.  **経済安保推進法に基づく認定の進展**
    **2026年2月17日には第6弾の「供給確保計画」認定**が実施済みであり、今後第7弾の募集も予定されている。第4回入札での優先約定を目指す事業者は、サプライヤーの認定状況の確認が急務である。
3.  **第4回入札（2026年度実施）の詳細確定**
    LNG募集量、水素・アンモニアの事前審査基準の詳細、蓄電池のペナルティ水準等について、2025年度（令和7年度）中のとりまとめを目指し、引き続き本作業部会で審議が継続される。
4.  **水素社会推進法に基づく予備審査の活用開始**
    オークションの事前審査として機能する予備審査の具体的な評価基準とスケジュールが確定次第、速やかに事業者への周知が行われる予定である。
