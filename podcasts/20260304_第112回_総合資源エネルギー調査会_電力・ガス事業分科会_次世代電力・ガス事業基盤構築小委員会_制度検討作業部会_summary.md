# 第112回制度検討作業部会資料：ベースロード市場運用・制度見直しに関するカスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）

本セクションでは、第112回制度検討作業部会の資料に基づき、実務担当者が把握すべきBL市場の現状と制度変更の背後にある戦略的論点を解説します。

1.  **2025年度第4回オークションの流動性枯渇とヘッジ機能の限界**
    今回の約定量は約0.5億kWh（前年度比56.4％）、約定率はわずか1.0％にまで低下しました。特筆すべきは、大規模発電事業者の供出が任意となったことで、旧一般電気事業者の売応札が「ゼロ」となった点です。これは、第4回オークションがベースロード電源の供給源としての機能を事実上喪失したことを意味します。小売電気事業者は、この回をヘッジ手段として計算に入れることは困難であり、スポット市場のボラティリティに直接晒されるリスクを再認識する必要があります。

2.  **市場範囲設定における「予見性」の優先とベイスリスク管理**
    制度設計上、エリア間値差に基づき市場を分割する「判断基準」が存在しますが、当局は頻繁な分割・統合を避ける姿勢を鮮明にしています。これは、細分化による流動性の低下や、市場範囲の変更がもたらす「ベイスリスク（拠点間価格差リスク）」の変動が、小売事業者の経営を圧迫することを防ぐ意図があります。実務的には、短期的な値差発生よりも、中長期的な制度の継続性が重視されています。

3.  **四国エリア分割見送りにみる技術的判断の整合性**
    関西ー四国間は「年間平均値差1.66円/kWh」「分断値差発生率36.4%」「30%超の月が7ヶ月」と、分割の判断基準をすべて満たしました。しかし、隣接する中国ー四国間が基準を満たさない中で四国のみを分割した場合、西日本エリア内で価格の整合性が取れなくなる「技術的課題」が生じます。このように、単一の連系線の数値だけでなく、ネットワーク全体の潮流と価格形成の連続性を考慮した判断が下されました。

4.  **間接送電権への移行を阻む「価格発見」とシステムの壁**
    暫定的な「値差清算」から恒久的な「間接送電権（ITR）」への移行が遅れている真の理由は、システム制約に加え、価格 discovery（発見）の困難さにあります。BL市場のオークションが4月に行われるのに対し、ITRの年間商品は9月取引開始とタイミングが乖離しており、売り手はBL応札時にITRの調達コストを価格転嫁できません。この不整合が解消されない限り、実務上のヘッジ手段として値差清算に頼らざるを得ないのが現状です。

### 2. 主要な議題

本会議で焦点となった、実務上の対立軸および検討課題は以下の通りです。

1.  **九州エリアの市場範囲統合と西日本の一体化**
    中国ー九州間の連系線分断状況が3年連続で判断基準（分断値差発生率30％以上等）を下回ったことを受け、九州を西日本エリアへ統合する妥当性が議論されました。九州ー関西間の平均値差は-0.86円/kWhと限定的であり、分割を維持する意義が薄れていることから、2022年以前の「2エリア体制」への回帰による取引の簡素化が目指されています。

2.  **値差損益の「補填・徴収」における閾値と事業者の収益性**
    スポット市場の分断リスクに対し、どの範囲で値差を補填・徴収すべきか、その「適応範囲」が論点となりました。事業者の予見性確保のため、現在の値差清算スキームを維持しつつ、過大な損失を回避するための閾値設定のあり方が、小売・発電双方の収益性に直結する課題として整理されています。

3.  **間接送電権の活用拡大に向けた環境整備と応札価格への織り込み**
    2026年度からの経過措置終了に伴う発行量増加はポジティブですが、売り入札者がITRコストを適切にBL価格に織り込めるかが最大の障壁です。特に、週間商品の価格見直しや年間商品の導入時期がBLオークションと同期していないため、売り手がリスクプレミアムを過大に積まざるを得ない状況をどう改善するかが問われています。

### 3. 決定事項

部会で承認・合意された具体的な確定内容は以下の通りです。

1.  **2025年度第4回オークションの確定結果**
    *   **約定量**：約0.5億kWh（前年度比56.4％）
    *   **約定率**：約1.0％（前年度1.6％から低下）
    *   **約定価格**：東日本12.39円/kWh、西日本11.15円/kWh（九州は約定なし）

2.  **2026年度BL市場の市場範囲再編（2エリア制への移行）**
    九州エリアを西日本エリアに統合し、全国を「東日本（北海道、東北、東京）」と「西日本（中部、北陸、関西、中国、四国、九州）」の2エリア制とすることを決定しました。これにより、広域的な取引の利便性向上が図られます。

3.  **値差清算の適用期間延長と「既約定分」の保護**
    間接送電権への完全移行が困難な状況を鑑み、2026年度オークションで約定する1年商品（2027年度受渡し分）および2年商品（2027・2028年度受渡し分）への値差清算適用を継続します。また、2024年度オークションで約定済みの2年商品の2026年度受渡し分についても、既定のルール通り値差清算が適用されることが確認されました。

4.  **西日本市場の基準エリア設定の固定**
    九州統合後の西日本エリアにおいて、市場の連続性と過去の経緯を重視し、引き続き「関西エリアプライス」を基準エリアプライスとして採用することが確定しました。

### 4. 今後のタイムライン

今後の制度運用および市場動向に関する重要スケジュールは以下の通りです。

*   **2026年3月4日**：第112回制度検討作業部会（市場範囲および値差対応の決定）
*   **2026年4月**：2026年度BL市場オークション開始（西日本を統合した新エリア制での1年商品取引）
*   **2026年6月**：新たな連系線での間接送電権取引開始（北海道→東北、東北→東京、関西→中国（逆方向）等の6月受渡し分より）
*   **2026年9月**：間接送電権「年間商品」の取引開始（2027年度受渡し分を対象とした本格的なヘッジ手段の提供）
*   **2026年度中**：2027年度オークション以降の値差対応の再検討。ここでは中長期市場の創設動向を踏まえた、**BL市場自体の「発展的解消」を含めた抜本的な見直し**が議論の焦点となる見通し。
