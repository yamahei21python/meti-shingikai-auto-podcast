# 第11回次世代電力系統ワーキンググループ：系統容量の「空押さえ」解消に向けた新規律の全容

### 1. ポッドキャスト解説ガイド（内容のポイント）

第11回次世代電力系統ワーキンググループ（WG）では、電力系統の公平なアクセス確保に向け、大規模需要家および発電事業者に対する規律強化の具体的運用が示されました。実務上、特に重要となるのは以下の3点です。

*   **局地的な大規模需要に対する規律（30MW超）の導入**
    データセンター等の大規模需要が系統容量を占有しながら実際には使用しない「空押さえ」を防ぐため、最終契約電力30MW以上の需要家を対象に「容量開放」や「費用精算」のペナルティ制度を導入します。計画通りに電力を使用しない場合、確保した容量を他者に開放するか、設備形成に要した費用を精算することが義務付けられます。
*   **系統アクセス手続きの厳格化と「土地使用権原」の要件化**
    事業確度の低い案件を排除するため、系統用蓄電池等の発電設備に対し、一事業者あたりの接続検討回答数に上限（東京11件、関西12件等）を設定します。また、契約申込時には土地の使用権原（登記簿や賃貸借契約書）の提出が義務化されます。ただし、既設設備の改修や、追加の土地取得を伴わない出力増加などの案件は例外として除外される方針です。
*   **既存契約への遡及適用と「自主的な見直し」の推奨**
    新規律は既契約の未稼働案件にも適用されます。需要家は2027年度初頭の本格導入までの猶予期間中に、自ら計画を適正な規模へ見直すことで費用精算（ペナルティ）を回避し、不要な容量を円滑に開放することが可能です。早期の計画修正が事業リスク低減に直結します。

### 2. 主要な議題

本会議では、限られた系統資源をいかに効率的に配分し、コスト負担を適正化すべきかが議論の焦点となりました。

*   **大規模需要による不適切な系統占有と託送料金への影響**
    特定の需要家が過大な容量を確保し続けることは、他者の接続阻害だけでなく、不必要な設備増強による託送料金の上昇を招き、全需要家の負担を増大させます。この懸念に対し、確実な需要に基づかない容量確保を是正する「容量開放」の有効性が議論されました。
*   **事業確度の確認と実務上の例外規定**
    手続き面の規律導入にあたり、既存事業者の予見性を損なわない運用が検討されました。特に、既設設備の更新・改修や出力増加で土地の追加取得を伴わないケースなど、既に事業継続性が確認できている場合は土地権原の提出を不要とするなど、実務に即した柔軟な例外規定の是非が論点となりました。
*   **個別帰属が困難な場合の「費用精算」の妥当性**
    変電所新設などの広範囲な設備増強では、特定需要家に帰属する実費の算出が困難です。放置すれば費用の未回収分が託送料金に転嫁されるため、需要規模に応じた「一定の推定方法」を用いて公平な負担を求めるロジックの正当性が確認されました。

### 3. 決定事項

会議で合意、または事務局より示された具体的方針は以下の通りです。

1.  **大規模需要の閾値を「30MW以上」に設定**
    2020年度以降の新設特高需要家のうち、上位約1割を占める「最終契約電力30MW以上」を規律の適用対象と定義しました。
2.  **段階別契約の期間制限を原則「最大6年」に**
    不確実な将来予約を抑制するため、最初の供給開始から最終規模に達するまでの期間を原則「最大6年」に制限します。
3.  **手続き遅延に対する厳格なペナルティと起算点の明確化**
    供給承諾から3ヶ月以内の工事費負担金入金がない場合や、需要家都合による不備・変更が生じた場合は申込を取り消します。起算点を明確にするため、今後は「技術検討結果の回答」と「供給承諾」を同時に通知する運用へ変更されます。
4.  **接続検討数上限の運用（2026年8月1日開始）**
    エリアごとに一事業者あたりの上限数（東京11件、関西12件、中部7件など）を設定。2026年8月1日時点で「受付未完了」の案件から、この上限ルールが適用されます。

### 4. 今後のタイムライン

実務上の重要期限は以下の通りです。

1.  **2026年8月1日：接続検討数上限設定の運用開始**
    各一般送配電事業者のHPでの周知を経て、同日以降、上限を超える「未受付」の接続検討申込に制限がかかります。
2.  **2026年10月1日：土地使用権原の提出義務化および手続き規律の開始**
    関係規程を改正し、同日以降の契約申込に適用。連系承諾から2ヶ月以内に土地の使用権原を証する書類の提出が求められます。また、前述の「3ヶ月以内の入金期限」も同日より厳格運用されます。
3.  **2027年度初頭：大規模需要向け新規律（容量開放・費用精算）の本格適用**
    既存需要家への周知・見直し期間を経て、託送供給等約款の改正を伴う新規律を導入。容量開放の判定は、需要家が「変更申出を行った時点」の系統空き容量水準に基づき判断されます。
