# 改正電気事業法に伴うファイナンス支援制度と市場ルールの詳細設計

### 1. ポッドキャスト解説ガイド（内容のポイント）
改正電気事業法の施行に向け、電力広域的運営推進機関（OCCTO）を通じた新たなファイナンス支援の枠組みと、排出量取引制度（ETS）開始に伴う市場ルールの具体化が議論の焦点となっています。

*   **ファイナンス支援制度の具体化と民業補完の徹底**
OCCTOによる融資は、プロジェクト総額の3割程度を上限とする基本方針が堅持されました。特筆すべきは、単年度の借入調達額の全額がOCCTO融資のみで充当されることを原則禁止し、民間金融機関との協調融資を必須とした点です。これにより、官による民業圧迫を避けつつ、民間金融機関の継続的な関与を促すリスク分担構造が設計されています。

*   **大規模電源への融資対象要件の明確化**
融資対象となる発電設備の出力要件は、経済安全保障上の特定社会基盤事業者の基準を参考に「原則50万kW以上」と設定されました。単一基だけでなく、同一発電所内での複数基の整備・更新など、一体の計画として意思決定される場合は合計出力での判断が可能です。ただし、地理的・時間的隔絶がある無関係な案件の合算は認められず、投資判断の同一性が厳格に求められます。

*   **排出量取引制度（ETS）に伴う市場価格への反映ロジック**
ベースロード市場では、排出枠の購入費用をユニットごとの無償枠超過分に応じて按分し、供出上限価格への織り込みを認めます。一方、売却収益については、将来の義務達成や脱炭素投資への活用を条件に価格から控除しない方針です。容量市場においては、ETS関連費用はkWh単位の費用であるため「他市場収益」として扱い、応札価格には反映（控除）させないという市場間での整合性を重視した整理がなされました。

### 2. 主要な議題
*   **改正電気事業法に基づくファイナンス支援の詳細設計と投資予見性の確保**
電力広域機関による融資制度の実施に向け、融資総額の上限、金利設定手法、償還確実性の担保策、および案件の優先順位付けについて検討。大規模投資を必要とする事業者の投資予見性を高めるための実務的な枠組み構築が目的。

*   **小売電気事業の登録取消しに関する審査基準と市場健全性の向上**
適切な事業運営が困難な事業者を市場から排除するための具体的な判断指標や行政処分のプロセスの策定。不適切な事業者の淘汰を促進することで、電力市場全体の健全性と信頼性を維持・向上させることを目指す議論。

*   **卸取引等における排出量取引制度の取扱いと制度的整合性**
GX実現に向けた排出量取引制度の導入に際し、ベースロード市場や容量市場などの各市場における費用・収益の会計処理および価格反映ルールの策定。二重計上の防止や脱炭素投資への誘引を両立させるための制度設計の検討。

### 3. 決定事項
1. **融資総額の制限と民間協調の義務化**
プロジェクト全体の融資総額の3割程度を上限とし、かつ単年度の借入資金の全額を電力広域機関の融資で賄うことは認めない。民間金融機関との協調融資を原則とし、初期段階で融資割合が高まる場合には将来的な民間融資の意向（LOI等）を確認する。

2. **金利設定における期間差補正の導入**
貸付金利は対象事業者の社債市場利回りを基本指標とする。貸付期間と参照社債の残存期間の差異（期間差）については、国債のイールドカーブ（例：25年国債と10年国債の利回り差）を用いて補正を行い、合理的な民間水準並みの金利を設定する。

3. **融資対象となる電源の出力要件の定義**
安定供給への貢献度を重視し、原則として単一または一体の計画として合計出力50万kW以上の発電設備を対象とする。一体性の判断には、同一地点での整備、一体的な運用、投資決定主体の同一性などの関連性を必要とする。

4. **電力広域機関（OCCTO）の財務基盤維持ルール**
財政融資の償還確実性を担保するため、OCCTOは令和9年度以降、融資総額の4%以上の純資産および8%以上の高流動性資産を融資勘定内に維持することを義務付ける。

5. **一般送配電事業者による償還担保スキーム（ラストリゾート）**
万一、OCCTOが期日までに国庫償還することが困難となった場合には、安定供給のラストリゾートを担う一般送配電事業者から「特別会費」として必要な額を回収し、償還に充てる枠組みを設ける。

### 4. 今後のタイムライン
1. **融資案件の事前相談受付開始（2026年8月末目途）**
令和8年度（2027年3月実行想定）および令和9年度（2027年4月以降実行想定）の融資案件について、資源エネルギー庁による事前相談の受付を開始し、計画の早期精査を行う。

2. **改正電気事業法および関連政省令の施行（2026年12月頃）**
ファイナンス支援制度の法的根拠となる改正法の施行に合わせ、OCCTOの業務規程変更等の制度運用に向けた法的枠組みを確定させる。

3. **令和8年度第1号案件の融資実行（2027年3月頃）**
年度内の予算執行を完了させるため、年内（2026年12月）を目途に計画認定を行い、その後4か月程度を要する融資審査、大臣意見照会等の手続きを経て、2027年3月の融資実行を目指す。

4. **令和9年度以降の通常運用（2027年4月〜）**
令和9年度以降に融資実行を想定する案件については、前年度（令和8年度）内に計画認定を完了させる標準的なスケジュールへと移行する。
