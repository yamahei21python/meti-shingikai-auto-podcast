# カスタムレポート：長期脱炭素電源オークション制度見直しの要点

### 1. ポッドキャスト解説ガイド（内容のポイント）
令和8年（2026年）6月23日に開催された「第3回電力安定供給ワーキンググループ」における、長期脱炭素電源オークション第4回入札に向けた制度見直しの要点を、専門的視点から解説します。

* **資本コスト（WACC）の5.5%への引き上げ**
足下の金利上昇局面を捉え、第4回入札における資本コスト（税引前WACC）のベースを従来の5.0%から5.5%へと引き上げる案が了承された。これは、特定の月の変動に左右されないよう、日本銀行の「貸出約定平均金利」の2025年度平均値（1.51%）を参照指標としたものである。電源種別の範囲も、これに合わせて4.5%〜6.5%へと上方修正される。

* **バイオマス発電の対象継続と定義の明確化**
当初、一般木質バイオマス等はFIT/FIP制度の支援除外に合わせて本制度からも除外する方針であったが、供給力確保の必要性から方針を転換した。第4回入札では、一般木質・農産物（10,000kW以上）およびバイオマス液体燃料（全規模）を対象として継続する。これにより、他電源との価格競争を通じた脱炭素電源の確保を目指す。

* **LNG専焼の上限価格二極化と物価スライドの適正化**
新規地点での投資予見可能性を高めるため、上限価格を「基地整備あり（9.2万円/kW/年）」と「基地整備なし（6.5万円/kW/年）」に分離設定する。また、価格算定に用いる物価補正指標を、実態との乖離が指摘されていた「総資本形成デフレーター」から、より現場感覚に近い「建設工事費デフレーター（電力）」へと切り替える。

* **脱炭素電源の上限価格算定倍率の2倍への修正**
一般水力、揚水（新設）、原子力については、参照データが1990年代から2000年代の古いプラントのものであることを踏まえ、現下の資材高騰を反映させる措置を講じる。上限価格の算定倍率を、従来の諸元コストの1.5倍から2倍へと引き上げ、建設コストの急騰に対応した。

### 2. 主要な議題
本会合では、事業者の投資意欲を阻害しないための「投資予見可能性の確保」と「物価・金利動向の実態反映」が中心的な議論となりました。

* **全電源の資本コスト算定根拠の合理化**
金利上昇に伴う事業者の収益性低下を防ぐため、WACCの算定根拠を従来の1.41%（2025年暦年平均案）から、直近の趨勢を反映した1.51%（2025年度平均）へと修正する妥当性が議論された。また、落札後の金利変動リスクを軽減するため、毎年度の金利状況に応じた価格補正メカニズムの導入が不可欠であるとの認識が示された。

* **供給力不足リスクに対応するバイオマスの再定義**
脱炭素と安定供給の両立が急務となる中、バイオマス発電を「持続可能性のある脱炭素電源」として再評価する議論が行われた。FIT/FIPからの自立化を目指しつつも、オークションによる市場競争の枠組み（イコールフッティング）に乗せることで、効率的な電源確保を図る狙いがある。

* **建設資材価格高騰とデフレーターの乖離是正**
従来の価格設定の基礎となる「建設工事費デフレーター」が実際の資材価格上昇に追いついていない現状が指摘された。特に1990年代から2000年代の古いプラントデータを諸元とする電源種において、デフレーター補正のみでは応札価格が過小評価されるリスクを回避するため、算定倍率の見直しが焦点となった。

### 3. 決定事項
事務局案に基づき、第4回入札に向けて概ね了承された事項は以下の通りです。

1. **資本コストベースの5.5%への改定と補正適正化**
他人資本コストの参照指標を2025年度平均（1.51%）に固定し、全電源のベースWACCを0.5%加算する。あわせて、第4回入札以降の落札価格の自動補正において、「ベースWACC（5.5%）＋（X-1年の金利－入札年度の前年の金利）」という計算式を適用し、将来の金利変動を柔軟に反映させる。

2. **LNG基地整備費用の外出しと上限価格の再設定**
新たにLNGタンク、桟橋、ローディングアーム等の基地整備が必要な案件（石炭からのリプレース等）に対し、過去20年間の基地建設費平均（1,116億円）をモデルプラントに加算した。基地新設ありの案件の上限価格を9.2万円/kW/年と設定することで、インフラ未整備地点への投資を促す。

3. **一般水力・揚水（新設）・原子力の上限価格引き上げ**
物価上昇指標との乖離を埋めるため、算定倍率を2倍に変更する。この引き上げにより、揚水（新設）およびLDESの算定値は閾値を上回ることとなったため、上限価格は「20万円/kW/年」の閾値で据え置く（実質的な上限キャップの適用）。一般水力（新設）は192,739円/kW/年、原子力は193,810円/kW/年へと大幅に引き上げられた。

### 4. 今後のタイムライン
今後の制度運用および入札実施までのスケジュールは以下の通りです。

1. **詳細諸元の確定（次回以降の会合）**
今回方針が決定されたバイオマス発電について、具体的な上限価格および諸元の詳細を次回以降のワーキンググループで確定させる。太陽光、風力、地熱の上限価格についても継続して議論が行われる。

2. **第4回入札の実施**
2027年（令和9年）1月に第4回長期脱炭素電源オークションの入札実施を予定。今回の制度見直しを反映した募集要項が提示される。

3. **金利変動補正の運用開始**
第4回入札の落札案件から、毎年の金利変動を反映した落札価格の自動補正運用を本格化させる。これにより、20年間の契約期間中における事業者の金利リスクを最小化する仕組みを確立する。
