# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）

我が国のエネルギー政策は 安全性（Safety）を大前提に 安定供給（Energy Security） 経済効率性（Economic Efficiency） 環境適合（Environment） を追求する Ｓ＋3Ｅ の原則を軸としている。今般の中東危機における緊急的な備蓄放出という応急処置を経て 政策の焦点は地政学リスクの常態化を見据えた 供給構造の構造的強靭化 へと移行した。本ガイドでは ホルムズ海峡というチョークポイントを回避するための新たな法的 経済的アプローチと 自主開発権益および輸送インフラ確保の重要性を詳解する。

* **原油調達の多角化と現状の到達点**
官民連携によるホルムズ海峡迂回ルートの活用により 2026年4月の25パーセント（日量59万バレル）から 5月には62パーセント 6月には82パーセントと段階的に回復し 7月および8月には前年並みの10割（日量約240万バレル）の調達量を確保した。米国 アジア太平洋 中南米 アフリカなど 多角的な供給源からの代替調達が着実に実効性を上げている。

* **上流権益と輸送インフラ確保の重要性**
JOGMECを通じたリスクマネー供給により ＩＮＰＥＸによるアゼルバイジャンのＡＣＧ油田やオーストラリアのイクシスＬＮＧプロジェクトでのコンデンセート優先販売といった具体的な成果を得ている。単なる上流権益の確保に留まらず 有事の際に機能したサウジアラビアのヤンブーやＵＡＥのフジャイラといったホルムズ海峡外の拠点へ通じる 代替輸送経路（パイプライン） 事業への参画を支援することで 物理的な輸送権利の確保を目指す。

* **供給構造強靱化に向けた新制度の設計案**
特定のチョークポイントを回避する際に生じる 1バレルあたり2ドル程度の追加コスト（輸送費増やパイプライン利用料）という 外部不経済を内部化 するための「多角化納付金 交付金」制度を創設する。原油 ナフサ輸入業者全体から徴収する納付金を原資に 多角化に取り組む事業者へ交付金を支給することで 地政学リスクに伴う社会全体のコスト負荷を平準化する。

* **石油備蓄水準の回復に向けた具体的指針**
国家備蓄石油の放出後 段階的な回復プロセスを推進する。まずは2026年度中に ＩＥＡ基準90日分 の水準へ早期復帰させる。続く2027年度中には ナフサの国内精製分を含めた より実効性の高い指標である 原油輸入量90日分 水準への引き上げを目指す。これは備蓄日数の単なる回復に留まらず 供給構造の強靭化を反映した新たな安全保障水準の確立を意味する。

### 2. 主要な議題

* **石油等の供給構造における地政学的リスクの常態化**
中東情勢の緊迫化に伴い 2026年4月にはスポット運賃が前年同月比で約11倍にまで暴騰するなど 輸送費の激しい乱高下が発生した。国際価格指標を大きく上回る調達プレミアムの増大は社会経済の大きな負荷となっており 有事が日常化する環境下では 緊急避難的な対応から 構造的なコスト平準化メカニズムへの転換が不可欠であるという認識が共有された。

* **ナフサ等の特定石油製品における供給網の脆弱性**
今般の事態では 備蓄義務の対象外であったナフサの供給不安が露呈し シンナーや塗料など石油化学製品全般にわたる供給の偏りや流通の目詰まりが発生した。製造産業分科会との連携により 石油化学原料の安定確保を 産業政策（物資安全保障）の一環として捉え直し 原料代替やナフサ備蓄の在り方を含めた構造的対策を議論の遡上に載せている。

* **海上輸送における保険キャパシティの確保**
輸入の大部分を海上輸送に依存する我が国にとって Ｐ＆Ｉ保険（第三者賠償責任保険） 船舶保険 貨物保険の三種からなる海上保険の維持は安定供給の生命線である。情勢不安下で保険会社のリスク判断が厳格化する懸念を踏まえ 代替供給ルートにおいても必要な再保険市場のキャパシティを確実に確保し 安定的な輸送を継続できる国家的な枠組みの検討が必要とされている。

### 3. 決定事項

1. **JOGMECを通じた多角化支援制度の導入検討**
原油およびナフサの全輸入業者から徴収する「多角化納付金」を原資とし 多角化の取組を行う事業者に「多角化交付金」を支給する基本方針を確認した。経済性や多角化への寄与度を ＪＯＧＭＥＣ が厳格に評価し 国が調達計画を認定することで 官民のリスク分担を明確化した構造的な強靭化を図る。

2. **国家備蓄原油の段階的な回復目標の設定**
放出によって低下した在庫を二段階で回復させる。2026年度中にＩＥＡ基準の90日分を達成し 2027年度中にはナフサ相当分を加味した原油輸入量ベースで90日分の水準へと積み増す。これにより有事の供給持続力を強化し ホルムズ海峡への依存リスクを実質的に低減させる。

3. **上流権益 輸送事業への参画支援の拡大**
産油 産ガス国における本邦企業の自主開発比率向上に加え 代替輸送経路となるパイプラインの建設および増築事業への環境整備を強化する方針を固めた。特にヤンブーやフジャイラといった特定のチョークポイントを迂回する積出拠点へのアクセス権を確保するため リスクマネー供給機能のさらなる拡大を推進する。

### 4. 今後のタイムライン

1. **2026年9月11日 ＬＮＧ産消会議2026の開催**
ウェスティン東京にて 第15回目となる国際会議を開催する。テーマを 「将来に向けたＬＮＧの推進 強靭性と信頼性の確保」 と定め 中東情勢を受けた市場の強靭化や 安定供給確保に向けた投資の役割について 官民の代表による多面的な議論を実施する。

2. **2026年度中 ＩＥＡ基準90日分の備蓄水準への回復**
国家備蓄石油の段階的回復における最初のマイルストーンとして ＩＥＡ基準に基づく90日分の確保を完了させる。市場価格の動向を注視しつつ 速やかな在庫積み増しを断行し エネルギー安全保障の基盤を再構築する。

3. **2027年度中 原油輸入量90日分水準への備蓄回復**
ナフサの国内精製寄与分を含む より実効的な供給力を示す指標として 原油輸入量ベースでの90日分の水準を達成する。これは今般の危機以前よりも高い実質的な供給可能日数の確保を目標とするものである。

4. **石油等の供給構造の強靭化ＷＧによる制度具体化**
2026年7月に設置されたワーキンググループにおいて 多角化支援制度の具体的な認定要件や 実務上のフロー 納付金の算定根拠などの策定を加速させる。早期の制度運用開始に向けた詳細設計を完了し 法的 経済的な裏付けを持つ強靭化策を確立する。
