# プラスチック製容器包装及び分別収集物の再商品化入札制度の見直しに関する検討会（第3回） カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
本検討会では、日本の資源循環政策を「カスケード利用」から「高度な循環」へとシフトさせるための抜本的な制度設計が議論されました。業界関係者が把握すべき核心は以下の4点です。

*   **処理能力の逼迫と競争環境の抜本的改善：** 従来の「安定枠」は、全事業者に再商品化量を割り振ることで事業継続を担保してきましたが、これが結果として効率化や成長へのインセンティブを削ぐ「成長の阻害要因」となっていました。令和8年度からの枠組み一本化と安定枠の廃止により、意欲ある事業者が処理能力を最大限に活用できる環境を整備し、逼迫する国内の処理能力向上を図ります。
*   **材料リサイクルとケミカルリサイクルの融合意義：** 素材特性によりリサイクル率が低迷しているPS（25%）やPET（3%）の残渣処理を改善するため、「MR（材料リサイクル）×CR（ケミカルリサイクル）」のジョイント入札を解禁します。これにより、単一手法では困難だった再商品化率の向上を実現し、同時に莫大な設備投資を要する新規CR事業者の市場参入障壁を低減させます。
*   **動静脈連携による「出口戦略」の高度化とEPRの進化：** 再生材利用がパレット等に留まる現状を打破するため、製造業者（動脈）と再商品化事業者（静脈）を直接繋ぐ新枠を創設します。これは、特定事業者が負担する拠出金を原資とする「拡張的生産者責任（EPR）」に基づきつつ、再生材の需要予見性を高めることで、容器から容器へ戻す「水平リサイクル」等の高度利用を促進する政策的意義を持ちます。
*   **PCR（ポストコンシューマー）材の価値最大化と費用適正化：** プラスチックリサイクルの本質は、ビジネス由来のPIR（ポストインダストリアル）材ではなく、家庭から排出されるPCR材の循環にあります。物価高騰や人手不足を反映し「厳格な上限価格」から「適切な上限価格」へ移行することで、PCR材の再商品化事業の持続可能性を担保し、供給能力の増強を強力に支援します。

### 2. 主要な議題
実務上の対立軸や、法制度との整合性について、以下の4項目が焦点となりました。

*   **動静脈連携枠における対象製品と費用負担の整理：** 高品質再生材の安定需要確保に向け、対象を特定事業者（容器包装）に限定するか、あるいは「指定脱炭素化再生資源利用促進製品（自動車・家電等）」まで拡大するかが論点です。特に、容リ法上の費用負担義務がない他業界がこの枠を利用する場合の公平性や、EPRの観点からの正当性について慎重な議論が行われています。
*   **ジョイントグループ登録における実務的制約：** トレーサビリティの厳格な維持を目的として、ジョイント登録者は個別入札が制限されます。実務上の大きな課題として、現行のシステム制約上、当面は「1代表事業者・1構成事業者」のペアに限定される点が示されました。これは将来的に複数構成員へ拡大予定ですが、現時点ではグループ形成における戦略的な判断が求められます。
*   **「製品プラスチック」の取り扱いと自治体負担の不均衡：** プラ新法第33条に基づく自治体の再商品化計画により、容リプラ（区分1）と製品プラ（区分2）の混合収集が進んでいます。しかし、費用負担は「容リプラ＝特定事業者99%：自治体1%」であるのに対し、「製品プラ＝自治体100%」という格差があり、混合物の増加が入札価格や自治体財政に与える影響が深刻な議論となっています。
*   **ケミカルリサイクルにおける新手法の定義とガイドライン：** 技術革新に伴い、従来の油化に加えて「モノマー化」をガイドラインに新設する方針です。既存の油化手法と新手法の整合性を図るため、収率基準の明確化や、プラスチックへの再利用を前提とした炭化水素油の要件定義など、技術的妥当性を担保するためのルール作りが進行しています。

### 3. 決定事項
検討会で提示された、運用上の具体的な数値目標および基準は以下の通りです。

*   **令和8年度入札における「70%制限」の導入：** 材料リサイクル（MR）優先枠において、各事業者が落札できる上限を「処理能力の70%」に制限します。残りの30%を一般枠での競争に回すことで、市場全体の競争倍率を適正化します。入札順序は「動静脈連携枠 ⇒ MR優先枠 ⇒ 一般枠」というシーケンスが予定されています。
*   **等価的統合収率（Zeq）による施設審査基準の策定：** MRとCRを組み合わせた際の公平な評価指標として `Zeq = (B + C × (45 / CR基準)) / A` を導入します（A:投入量、B:MR製品量、C:CR製品量）。基準値を「Zeq ≧ 45%」と設定し、各CR手法（油化、高炉、ガス化等）の特性を反映した統合評価を実施します。
*   **動静脈連携枠の段階的拡大目標：** 導入初年度は全体の数％の割り当てから開始し、市場の習熟度を見極めながら「最大20％程度」まで拡大する目標が提示されました。この枠の原資は、MR優先枠と一般枠から等分に捻出し、20％適用時には各枠を40％まで縮小させる計画です。
*   **再生材の利用事業者制限の緩和（MRからCRへの連携）：** 令和8年度のガイドライン改定を経て、令和9年度入札分から、MRで製造された中間製品（フレークやペレット）をCR事業者へ販売し、残渣のさらなる高度利用を図ることが認められる方針です。ただし、この適用範囲を一般枠のみとするか、優先枠を含めるかは継続審議となります。

### 4. 今後のタイムライン
令和8年度から令和10年度の本格運用に至るスケジュールは以下の通りです。

*   **令和8年4月中旬：** 第4回検討会の開催。動静脈連携枠の詳細設計や、ジョイントグループ登録の具体的な事務手続きについて検討。
*   **令和8年5月末：** 第5回検討会の開催。制度見直し案の最終とりまとめ、および日本容器包装リサイクル協会等との実務協議。
*   **令和8年度内（7月〜11月）：** 令和9年度入札に向けた再生処理事業者の登録申込開始。7月に登録説明会を実施し、審査を経て11月に判定予定。
*   **令和9年度以降：** 「動静脈連携枠」の運用開始、および「MR×CRジョイント制度」の施行。
*   **令和10年度運用開始分：** ケミカルリサイクルの「モノマー化」や「油化収率」の新基準を盛り込んだ、改定版ガイドラインの完全適用開始。
