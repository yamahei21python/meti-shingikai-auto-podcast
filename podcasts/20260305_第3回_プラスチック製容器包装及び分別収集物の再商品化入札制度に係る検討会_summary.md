# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
本検討会における議論は、従来の「処理量の安定確保」を優先したフェーズから、再商品化の「質」を評価軸に据える歴史的転換点へと差し掛かっています。令和9年度からの新制度導入は、事業者にコスト競争から技術・連携競争へのシフトを余儀なくさせるものであり、資源循環の付加価値を最大化させる「品質主導型モデル」への構造改革を意味しています。

* **令和8年度入札結果の総括と課題**
令和8年度入札は、最終的に全ての保管施設で落札が完了したものの、プロセスには深刻な課題が露呈しました。初回入札での未落札（上限価格超過）が前年度を大幅に上回る規模で発生し、全量を成約させるまでに計4回の入札を要しました。これは現行の上限価格設定と実コストの乖離を裏付けており、持続可能な事業継続に向けた価格算定ロジックの見直しが急務となっています。

* **材料・ケミカルリサイクルのジョイント登録解禁**
リサイクル率の飛躍的向上と新規事業者の参入障壁緩和を目指し、令和9年度入札から「材料リサイクル（MR）」と「ケミカルリサイクル（CR）」の共同入札（ジョイントグループ登録）が解禁されます。これにより、MRの工程で発生する残渣をCRが引き受ける補完関係が制度化され、従来は廃棄されていた素材の資源化による収率の最大化が期待されます。

* **動静脈連携枠の創設による高品質化の促進**
水平リサイクル等の高度な資源循環を実現するため、再商品化事業者（静脈）と製造事業者（動脈）が直接連携する「動静脈連携枠」が創設されます。動脈企業による再生材の利用コミットメントや品質評価への関与を制度に組み込むことで、需要の予見性を高め、これまでコスト面で困難だった高品質再生材の安定的な供給体制を構築します。

* **等価的統合収率（Zeq）による評価指標の導入**
異なるリサイクル手法を組み合わせる際の公平な評価軸として、「等価的統合収率（Zeq≧45％）」が導入されます。これは、手法ごとに異なる基準収率（MR 45%、コークス炉 85%等）を「MR相当の価値」に換算して合算する仕組みです。この等価性の導入により、高収率なCR技術がジョイントにおいて不当に有利、あるいは不利にならない公平な技術評価が担保されます。

### 2. 主要な議題
* **ジョイントグループにおける事業者構成の制限**
現行の事務システムの制約から、当初のジョイント登録は「1代表者・1構成事業者」に限定される方針です。これに対し、MRに比べ圧倒的に巨大な処理能力を持つCRの特性を考慮し、1つのCR施設が複数のMR事業者と連携する「1対複数」の体制を求める業界側の指摘が相次ぎました。これは大規模CRプラントの稼働効率を維持するための「規模の経済」に基づく切実な要望となっています。

* **動静脈連携枠における費用負担の公平性**
動静脈連携枠に、容リ法の費用負担者（特定事業者）以外の業界（自動車・家電等の指定脱炭素化再生資源利用促進事業者）を参画させることへの是非が議論となりました。既存の特定事業者が負担した拠出金が、費用を負担していない他業界への原料供給に流用されることへの「フリーライダー（ただ乗り）」懸念に加え、自治体が意図しない処理費用の増大を懸念する声も上がっています。

* **再商品化製品の利用制限見直しとガイドライン改定**
MRで製造された製品（ペレット等）をCR事業者に販売可能とするガイドラインの改定が論点となっています。対象を「モノマー化・油化等によるプラスチックへの還流（循環型CR）」に限定するか、「残渣利用を含む全手法（全CR）」まで広げるかによって市場規模が大きく変わるため、資源循環の優先順位と実務的な出口戦略の整合性が問われています。

### 3. 決定事項
1. **令和9年度入札からのジョイントグループ運用開始**
令和9年度入札より、材料・ケミカルリサイクルのジョイント入札を先行開始することが決定しました。システムの都合上、当面は「1代表者・1構成事業者」の組み合わせとし、代表事業者が札入れ、一括管理、再商品化実施料金の請求・受領を一括して担う運用が採用されます。

2. **動静脈連携枠の段階的導入方針**
動静脈連携枠は、導入初年度は全量の数％から開始し、将来的に最大20％まで拡大するロードマップが示されました。契約形態は単年を基本としつつも、動脈側の安定調達ニーズに応えるため、次年度以降の落札優先権（例：3年間の有期優先権）を付与する方向で検討が進められます。

3. **収率算定方法の等価性確保**
ジョイント全体の評価指標として、`Zeq = (MR収率 + CR収率 × (45 / CR基準収率)) / 投入量` という算定式が採用されました。油化(45%)、高炉還元剤(75%)、コークス炉(85%)、ガス化(65%)といった各手法の収率基準を等価的に統合し、グループ全体でZeq≧45％を満たすことを登録の絶対要件とします。

### 4. 今後のタイムライン
1. **令和8年4月中旬：第4回検討会の開催**
総合的評価方式の評価項目見直しや、動静脈連携枠の具体的評価指標（動静脈連携性評価方式）の詳細設計、およびモノマー化の制度上の位置づけについて、実務に即した継続議論が行われます。

2. **令和8年5月末：第5回検討会の開催**
ジョイントグループ登録の最終的な枠組み確定や、再商品化製品の利用制限に係るガイドライン改定案の取りまとめが行われる、制度設計の最終段階となります。

3. **令和8年7月：令和9年度入札に向けた事業者登録開始**
策定された新制度に基づき、日本容器包装リサイクル協会による再商品化事業者の登録受付および審査が開始されます。ジョイント登録や動静脈連携枠への参画を狙う事業者にとって、戦略的な申請が求められる重要な節目です。
