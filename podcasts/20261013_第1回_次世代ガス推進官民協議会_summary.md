# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
2021年6月に設立されたメタネーション推進官民協議会は、2050年カーボンニュートラルの実現に向け合成メタンの導入検討を進めてきたが、熱需要の脱炭素化やエネルギー安定供給、経済成長の観点からバイオガスの重要性が著しく高まったことを受け、2026年10月に「次世代ガス推進官民協議会」へと改組・新設された。第1回協議会では、合成メタンとバイオガスを「次世代ガス」と一体的に位置づけ、既存の都市ガス導管や消費機器をシームレスに活用する官民タイムラインの共有および、国内の技術開発・制度設計と海外の政策動向・国際枠組みへの対応に関する包括的な議論が行われた。

* **協議会の名称変更と次世代ガス全般への対象拡張**
従来は合成メタンを中心に検討を行ってきた官民協議会を改組し、バイオガス（バイオメタネーション含む）を含む次世代ガス全般へと対象を拡大した。排出削減が困難な熱需要分野における脱炭素手段としてだけでなく、エネルギーの調達多角化や自給率向上、地産地消に寄与する次世代ガスについて、官民でタイムラインやロードマップを共有する推進体制が構築された。

* **国家戦略における合成メタンおよびバイオガスの明確な位置付け**
閣議決定された「経済財政運営と改革の基本方針2026」や、第17回GX実行会議で示された「エネルギー需給構造の強靱化総合パッケージ（パワーGX）」において、天然ガスや合成メタン、バイオガスへの燃料転換がエネルギー需給の強靱化および自給率向上のための核心施策として位置付けられた。

* **技術開発の高度化とクリーン燃料証書制度の実証**
グリーンイノベーション（GI）基金において、大阪ガスのSOECメタネーション（ベンチスケール10 Nm³/h級）や東京ガスのハイブリッドサバティエ（ベンチスケール1 Nm³/h級）がステージゲート審査を通過した。総合エネルギー変換効率60%以上の実現に向けた技術開発が進むとともに、2026年度には資源エネルギー庁および事務局委託先のBIPROGY連携のもと、東京ガス、大阪ガス、INPEX等とデジタル管理基盤を用いた証書発行・移転・償却の実証実験が推進される。

* **国際的なサプライチェーン管理と制度・ガイドラインへの対応**
温室効果ガス排出量算定・報告・公表制度（SHK制度）におけるマスバランスやブックアンドクレーム適用の検討が進められている。また、IPCC第7次評価報告書（AR7）のCDR/CCUS方法論報告書執筆への秋元委員等の参画や、GHGプロトコルのスコープ2ガイダンス改定に対する経済産業省からの意見提出など、国際ルール形成への主体的な働きかけが行われている。

### 2. 主要な議題

* **次世代ガス推進官民協議会への改組と対象範囲の拡大**
熱需要の脱炭素化、エネルギー安定供給、経済成長の同時達成に向け、従来の合成メタンに加えてバイオガスを一体的に取り扱う必要性が議論された。我が国の総合エネルギー統計における国内バイオガス産出量は91 TJ（2024年度）にとどまる一方、欧米では精製によるバイオメタン化（デンマーク80%、米国48%等）が進んでおり、国内バイオガスの利活用加速に向けた官民のタイムライン共有と環境整備が重要議題となった。

* **国内における技術開発とクリーン燃料証書制度の検証**
GI基金による革新的メタネーション技術において、ベンチスケールでの総合エネルギー変換効率60%以上達成に向けた進捗が確認された。また、2026年度に実施されるクリーン燃料証書制度の実証実験に関し、資源エネルギー庁やBIPROGYが管理するシステム基盤上で、ガス製造事業者から需要家に至る設備登録、証書発行、取引・移転、無効化（償却）のプロセスおよび、取引所取引・相対取引を含む具体的運用スキームが議題となった。

* **海外におけるバイオガス・合成メタンの市場動向と調達環境**
欧州のREPowerEUにおける2030年350億m³バイオメタン目標、米国のインフレ抑制法（IRA）やカリフォルニア州LCFS、中国の2030年バイオメタン200億m³国家目標、インドの新GOBARdhan（2026年開始、CBG買取価格43%引き上げ・生産量約10倍化）など主要国の政策が共有された。原料面では欧州の農業残渣シフトや米国の埋立地ガス利用等の特徴が示され、合成メタン製造における生物起源CO2のハブ化調達やEU RED委任法に基づくCO2控除期限等の調達要件が議論された。

* **温室効果ガス算定・国際制度（SHK・IPCC・GHGプロトコル）との整合性**
国内SHK制度での複数燃料混合時におけるサプライチェーン管理手法（マスバランス・ブックアンドクレーム）の整理方針が議論された。IPCC AR7 CDR/CCUS方法論報告書における日本人有識者の参画状況の報告に加え、GHGプロトコルスコープ2改定に対し経済産業省が提出したパブリックコメントが共有された。同パブコメでは経団連（1,500社以上）等の懸念を背景に、算定の複雑化による削減リソース圧迫、非化石証書やPPAを通じた再エネ導入の著しい抑制リスク、日本の地理的特徴への配慮不足を指摘し、透明な対話と段階的な移行措置を強く求める姿勢が示された。

### 3. 決定事項

1. **協議会名称の「次世代ガス推進官民協議会」への変更と設置**
合成メタンを中心に議論を進めていた旧協議会を改組し、バイオガスを含めた次世代ガス全般の普及拡大とタイムライン共有を図る組織として、2026年10月に「次世代ガス推進官民協議会」を新たに設置することが決定された。

2. **革新的メタネーション技術開発（GI基金）の事業継続決定**
GI基金を活用した技術開発において、2025年1月に実施されたステージゲート審査により、大阪ガスのSOECメタネーションおよび東京ガスのハイブリッドサバティエの取り組みが通過し、要素技術を統合した革新的システムの開発（第2フェーズ）への事業継続が決定された。

3. **クリーン燃料証書制度の2026年度実証事業の実施決定**
需要家・事業者へのヒアリング結果を踏まえ、2026年度に資源エネルギー庁、BIPROGY、東京ガス、大阪ガス、INPEX、関係ガス事業者、認証機関、需要家が連携し、システム上での設備認定から証書発行、移転、償却に至る一連のプロセスを実証する方針が決定された。

4. **SHK制度におけるサプライチェーン管理要件の整理方針の明確化**
SHK制度において、商業化が進む燃料を優先テーマとして選定し、マスバランスやブックアンドクレーム等の管理手法を許容するための要件整理に向け、業界ヒアリングおよび省令・マニュアル改正の検討を進める方針が決定された。

### 4. 今後のタイムライン

1. **2026年度（令和8年度）**
2026年10月の第1回次世代ガス推進官民協議会の発足を受け、同年度中にSHK制度における優先テーマのサプライチェーン管理要件の議論および省令・マニュアル等の改正を推進する。あわせて、資源エネルギー庁・BIPROGY・東京ガス・大阪ガス・INPEX等によるクリーン燃料証書制度のデジタルシステム実証実験を実施予定である。

2. **2027年度**
2026年度の実証実験結果を踏まえてクリーン燃料証書制度の社会実装の是非を判断する。また、SHK制度で整備されたサプライチェーン管理要件に基づき、2026年度実績を反映したGHG排出量の算定・報告を開始する。

3. **2030年および2030年代**
2030年目標として、日本による都市ガスへの合成メタン等1%導入目標の達成を目指す。国際的には、EUのREPowerEUに基づく年間350億m³バイオメタン生産目標および中国の国家目標である年間200億m³バイオメタン生産目標の達成年であり、インドの新GOBARdhanによるCBG生産量約10倍化が推進される。さらに、米国のDivert社による35基の食品残渣由来バイオメタンプラント開発目標に向けた展開が2030年代にかけて推進される。

4. **2035年〜2040年以降**
EU RED委任法において、合成メタン原料CO2の排出控除期限（EU-ETS対象の発電設備由来は2035年まで、その他産業設備由来は2040年まで）を迎えるため、大気直接回収（DAC）や持続可能なバイオマス起源CO2への移行が加速する。これらを経て、2050年カーボンニュートラルの実現に向けた長期ロードマップを推進する。
