# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
資源エネルギー庁が2026年3月に公表した本報告書は、電力システム改革の改革方針決定から10年の節目を迎え、法制度上の検証規定に基づき実施された総括的な評価をまとめたものです。安定供給の確保、電気料金の抑制、需要家の選択肢拡大という当初の3目的に対しては一定の成果が認められた一方、供給力不足や脱炭素化、国際的な燃料価格高騰といった新たなリスクへの対応が急務となっています。本レポートでは、自由化のメリットである「選択」と「競争」を維持しつつ、安定供給と脱炭素を両立させる次世代電力システムの具体的な設計図を提示しています。

*   **安定供給を大前提とした脱炭素電源への投資促進**
    再エネの導入拡大に伴い、火力発電が「ミドル・ピーク電源」へと役割を変え稼働率が低下する中で、発電事業者がLNGの長期契約を締結しにくいという構造的課題に直面しています。これに対し、事業者の燃料調達状況を国が継続的に把握する仕組みを構築するとともに、長期脱炭素電源オークション等の活用により、投資の予見性を高め、過渡期における供給力不足を回避する方針を明確にしています。

*   **次世代ネットワーク整備に向けたファイナンス支援の拡充**
    データセンターの急増や再エネ連系に対応するため、用地取得や機材調達の長期化（リードタイム）がボトルネックとなっている地内系統の計画的整備を加速させます。電力広域的運営推進機関（OCCTO）による貸付制度を大規模な地内基幹系統にも適用し、政府の信用力を背景とした財政融資の活用や託送料金の前倒し回収措置を講じることで、大規模な系統投資に伴う資金調達リスクを軽減します。

*   **同時市場の導入と小売事業者の規律強化による市場機能の進化**
    エネルギー価格の安定と需給運用の効率化を目指し、電力（kWh）と調整力（ΔkW）を同時に約定させる「同時市場」の導入検討を本格化させます。これは既存の卸市場や需給調整市場を代替する位置づけであり、市場構造の根本的な転換を意味します。同時に、小売電気事業者に対しては、過去の市場混乱の教訓から量的な供給能力（kWh）の確保を義務付け、安定的な供給責任を果たすための規律を強化します。

### 2. 主要な議題
本WGでは、電力自由化の進展と脱炭素化という二大潮流の中で生じた、実務上の不可避な課題について詳細な議論が行われました。

*   **安定供給に必要となる燃料の確保**
    自由化による販売先の不確実性増大に加え、再エネの優先給電により火力の稼働率が低下（ミドル・ピーク電源化）したことで、発電事業者がLNG等の燃料を長期契約で安定確保することが困難になっています。2030年以降、多くの長期契約が満了を迎える中、事業者がスポット価格の変動リスクに過度にさらされることで、日本のエネルギー安全保障が脅かされる懸念が大きな論点となりました。

*   **地内系統の計画的な整備を促す仕組み**
    再エネの連系やデータセンター等の大規模な需要増加に対し、従来の都度対応的な系統整備では、用地取得や地元理解、機材調達といった数年単位のリードタイムに対応できず、需要家の投資意欲を阻害する要因となっています。特に大規模かつ基幹的な地内系統において、一般送配電事業者が作成した長期計画を国が確認し、先行的・計画的な投資を可能にする仕組みの構築が議論の焦点となりました。

*   **小売電気事業者の責任・役割の遵守を促す規律**
    国際燃料価格の高騰に伴い、スポット市場に過度に依存していた一部の小売事業者が撤退・退出し、需要家に不利益を与えた経験から、事業者の供給能力確保に対する規律が改めて問われています。将来の需要に対してあらかじめ量的な供給能力（kWh）を確保する義務の妥当性や、市場の予見性を高めるための中長期取引市場の整備の必要性が議論されました。

### 3. 決定事項
WGでの議論の結果、次世代電力システムの構築に向けた具体的な制度変更および新設枠組みが以下の通り決定しました。

1. **小売電気事業者に対する量的（kWh）供給能力確保の義務化**
    2030年度の供給計画から、小売事業者に対し実需給の3年度前（N-3）および1年度前（N-1）に想定需要の一定割合の供給力を確保することを義務付けます。確保基準はN-3で5割、N-1で7割を軸としますが、実務的な影響を考慮し、小規模事業者はN-3で2.5割、N-1で5割とする緩和条件が決定されました。

2. **地内系統整備への電力広域的運営推進機関による貸付適用**
    大規模かつ基幹的な地内系統の先行的・計画的な整備を支援するため、国や広域機関が確認した整備計画をOCCTOによる貸付制度の対象に加えます。また、値差収益の取扱いを柔軟化し、大規模な地域間連系線の整備段階においては、値差収益を交付よりも貸付けに優先的に充当し、民間融資の返済を優先することも認める方針が確定しました。

3. **政府の信用力を活用した新たな融資制度の創設**
    長期・大規模な電源投資や系統整備を支援するため、OCCTOを通じた財政融資の活用を決定しました。民間金融機関との協調（官民協調・民業補完）を原則とし、投資期間が10年以上の案件を対象に、低利かつ安定的な資金を供給します。万一の際の償還を確実にするため、一般送配電事業者から拠出金を回収するラストリゾート的な枠組みも設けます。

4. **同時市場の導入に向けた詳細設計フェーズへの移行**
    kWhとΔkWを同時に取引する同時市場について、SCUC・SCED（系統制約を考慮したコスト最小化計算）やThree-Part Offer（起動費・最低出力費用・増分費用を用いた入札）、アップリフト（不足費用の個別補償）といった技術的要素を盛り込んだ詳細設計（第1フェーズ）と、システム要求定義（第2フェーズ）への移行を決定しました。これは、自己計画電源の概念を維持しつつ、市場の効率性を極大化する根本的な改革となります。

### 4. 今後のタイムライン
確定した制度の円滑な導入に向け、以下のスケジュールに従って実務が進められます。

1. **2026年夏季に向けた需給対策の実施**
    2026年8月の東京エリアにおける予備率が0.9%という極めて厳しい予測（速報値）を受け、既存の容量市場の見直しや予備電源制度の活用、およびkW公募等による短期の追加供給力調達を速やかに実行します。

2. **2030年度供給計画からのkWh確保義務の適用開始**
    小売電気事業者に対する量的な供給力確保義務は、2030年2月に提出される2030年度の供給計画から適用を開始します。それに先立ち、事業者の取引状況の継続的な検証や、中長期取引市場の具体的な設計を段階的に進めます。

3. **地域間連系線等の費用回収ガイドラインの作成**
    工事費用の増額時における回収の確実性を担保するため、工事費および運転維持費に対する検証の考え方を示すガイドラインを2025年度内（2026年3月末まで）を目途に作成します。これにより、大規模投資の予見性を高め、着実な系統整備を促します。

4. **同時市場のシステム要求定義と詳細設計の進展**
    同時市場の導入可能性を最終判断するための実務的な詳細設計およびシステム要求定義を加速させます。検討結果に基づき、運営主体の決定や市場開設準備、システム開発のフェーズへと順次移行する予定です。
