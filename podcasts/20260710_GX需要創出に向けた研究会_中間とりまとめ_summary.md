# 「GX率先実行宣言」の抜本的見直しと需要創出に向けた新たな枠組み

### 1. ポッドキャスト解説ガイド（内容のポイント）

* **GX需要創出の機運醸成と初期需要の立ち上げ**
成長志向型カーボンプライシング構想を前進させるためには、供給側のGX投資を需要側から支える「需要創出のサイクル」が不可欠です。本研究会の中間とりまとめでは、初期需要の立ち上げにおいてGX製品を積極的に選択・調達する企業の役割を定義し、その貢献を「見える化」する仕組みが提示されました。地政学リスクに伴うエネルギー危機の中で、GXは単なる環境対策を超え、エネルギー安全保障や産業自律性を確保するための「危機管理投資」へとその重要性を変質させています。

* **プラチナグレードの創設による評価体系の刷新**
従来のブロンズ、シルバー、ゴールドの区分を抜本的に再編し、国の目標と同等以上の野心的な調達目標にコミットする企業を「プラチナグレード」として最高位に位置付ける仕組みが導入されます。この新グレードは、事業活動との密接な関連性や定量的な閾値を要件としており、真にGX需要創出に貢献する企業を明確に識別・評価することを目的としています。政府目標がない製品についても、経過措置として排出削減インパクトや投資額割合を用いた判定基準を設けることで、多様な製品での調達を促します。

* **削減実績量の見える化とGXスチールの先行導入**
技術開発段階にある多排出産業の脱炭素移行を促すため、投資による削減努力を適切に評価する「GHG排出削減実績量」の考え方が導入されました。具体例として、鉄鋼分野では「GXスチールガイドライン」に基づき、マスバランス方式やアロケーション方式を活用した製品が率先実行宣言の対象となります。これにより、大規模なGX投資を要する産業構造転換の過程であっても、その削減価値を市場で評価し、投資回収を支援する環境を整備します。

### 2. 主要な議題

* **調達側から見た対象製品・サービスの定義の不明確さ**
現行の制度は供給側の技術視点で区分されているため、調達を行う企業にとっては、自社の事業にどの製品が該当するのか、定義や範囲が分かりにくいという構造的課題がありました。この認識の乖離が、需要側企業の積極的な宣言や具体的なアクションを阻害する一因となっていました。

* **需要創出への貢献度合いを測る定量的閾値の不在**
現行グレード判定は目標が「定量的」であれば足り、具体的な調達量の「閾値（しきいち）」が設定されていなかったため、企業の宣言が実際の市場形成や需要創出にどの程度寄与しているのかを客観的に評価する基準が欠落していました。このため、野心的な取り組みを行う企業が正当に評価されない懸念がありました。

* **事業活動と調達行動の関連性の希薄さ**
自社の主要な排出源や本業とは関連性の薄い製品での宣言が可能であった現状も課題視されました。事業活動と調達行動が乖離した宣言は、企業の脱炭素経営としての実効性が疑われるだけでなく、ステークホルダーからの信頼や投資呼び込みに繋がりにくいという弊害が生じていました。

### 3. 決定事項

* **プラチナグレード取得のための3つの判定基準（A・B・C）の設定**
新たな認定基準として、規模を問わず設定可能な比率指標が導入されました。第一の「A：調達目標」では、低炭素水素・アンモニア・合成メタンは1%以上、SAFやグリーンスチールは10%以上という政府・業界目標に基づく具体的数値を原則的な閾値とします。第二に、政府目標がない場合の「B：排出量削減率」では、取組スコープ内の削減量を reducible な Scope 排出量（鉄鋼ならScope 3 Cat 1等）で除して算出します。第三に、投資規模を測る「C：GX製品投資額割合」は、GX製品調達金額を全社売上原価で除して算出します。BおよびCの閾値は、試算結果の「中央値」を基準に設定されます。

* **業種別ポジティブリストの導入と対象製品の明確化**
事業活動と密接に関連する製品を評価するため、業種別の「ポジティブリスト」が策定されました。このリストには、鉄鋼・化学・セメントなどの製造業だけでなく、SAFフライトが関連する金融・保険業や、グリーンケミカルが該当する化学業など、広範なセクターが含まれています。各企業は、主要な排出源や事業内容に基づき、自社努力で削減可能な製品を優先的に選択することが求められます。

* **GX推進機構を通じた公表・フォローアップ体制の強化**
透明性を担保するため、GX推進機構のウェブサイトにおいて「宣言製品単位」で各社の取得グレードが公表されます。また、年に1回の頻度で取組状況のフォローアップ回答を義務付け、その内容を開示するとともに、フォローアップ会合を通じた実態把握が行われます。未回答や宣言不履行が確認された場合には、プラチナグレードの取り下げや取り消しも検討する運用ルールが合意されました。

### 4. 今後のタイムライン

* **見直し後のGX率先実行宣言の募集・認定開始**
2026年秋頃を目処に、刷新された制度に基づく新規募集および認定が開始されます。これに合わせて、事務局ではマニュアルの整備やオンライン受付システムの構築を進めるほか、企業向けの制度説明会を実施し、新基準への移行に向けた周知を徹底します。

* **年次フォローアップとヒアリング会合の実施**
プラチナグレード取得企業を主対象として、認定後の進捗状況を年次で確認する体制を構築します。進捗回答の公開だけでなく、定期的なフォローアップ会合におけるヒアリングを通じて、宣言の実行性を継続的にモニタリングし、実効性のある需要創出を担保します。

* **運用を通じた制度の継続的な改善と検証**
制度開始後は、プラチナグレードの取得企業数や製品ごとの認定状況を詳細に分析します。本制度が実際にGX製品の需要創出にどれだけ寄与しているかを検証し、その結果に基づき、現在は目標設定のない製品への新たな閾値設定や、市場環境に合わせた更なる制度改善を適宜実施していく方針です。
