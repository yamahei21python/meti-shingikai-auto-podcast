# 再生可能エネルギー主力電源化と2027年制度改革に向けた実務指針

### 1. ポッドキャスト解説ガイド（内容のポイント）
2026年6月24日に開催された「再生可能エネルギー主力電源化小委員会（第2回）」は、2030年度のエネルギーミックス達成に向けた残容量26から40GWの確実な積み上げと、2040年を見据えたFITおよびFIP制度の抜本的見直しを主導する重要な節目となりました。本会合では、地上設置型太陽光の適地減少という構造的課題を背景に、2027年度からの支援重点化類型を特定するプロセスが示されており、業界関係者は既存のメガソーラー開発モデルから屋根設置や地域共生型モデルへの戦略的転換を迫られています。

* **太陽光発電の導入ペース維持と適地減少に伴う戦略転換**
2030年度目標の達成には今後5年間で年換算5から8GWの導入継続が不可欠ですが、国内の国土面積当たりの導入量は既に主要国最大級であり地上設置の適地は枯渇しつつあります。この限界を突破するため、政策の舵は「未利用地開発」から「既存建築物の有効活用」および「地域共生」へと明確に切り替わりました。

* **屋根設置太陽光に対する規制強化と新たな報告義務**
公共部門における2030年50パーセント、2040年100パーセントの設置目標達成に向けた率先実行に加え、民間部門では2026年4月より省エネ法に基づく設置状況の報告が義務化されます。これは単なる補助金によるインセンティブ提供にとどまらず、事業者の非化石転換への取り組みを可視化・強制する規制的枠組みへの移行を意味しています。

* **ペロブスカイト太陽電池の社会実装に向けた巨額投資と市場創出**
次世代太陽電池の量産化に向け、グリーンイノベーション基金は約250億円増額され、官民連携の技術確立に投じられています。東京都、大阪府、愛知県の3大都市圏が先行して導入目標を策定したことは、初期市場の形成において極めて重要なシグナルであり、2025年度からの国内事業化を強力に後押しします。

* **洋上風力発電におけるEEZ法整備と浮体式へのシフト**
2040年に最大45GWという野心的な目標を完遂するため、EEZ（排他的経済水域）への設置を可能にする改正法が2026年4月に施行されます。ベスタス社との協力覚書締結や国際標準化組織FLOWRAを通じた産業基盤整備が進められており、着床式から浮体式への技術シフトとサプライチェーンの国際連携が加速しています。

### 2. 主要な議題
* **2030年エネルギーミックス達成に向けた関係省庁の施策進捗状況**
環境省、国土交通省、農林水産省が所管する個別施策の最新導入実績を精査し、目標値との乖離を定量的に評価しました。特に空港の再エネ拠点化や公共施設への率先導入について、2025年度末時点の数値を基に2030年までの加速化策が検討されました。

* **2040年主力電源化を見据えた電源別の構造的課題と対応方向性**
地上設置太陽光の適地減少、風力発電の系統制約、地熱発電の開発リスクといった電源特有の障壁を再定義しました。2040年の脱炭素化に向けて、次世代技術の社会実装や大規模な地域間連系線整備に伴うファイナンスの在り方などが議論の遡上に載せられました。

* **FITおよびFIP制度における地域共生型への支援重点化の具体的定義**
これまでの急速な導入拡大に伴い顕在化した景観や安全上の課題を「負の外部経済性」として認識し、国民負担の抑制と地域理解を両立させるための支援対象の絞り込みを行いました。地域に真に受け入れられる電源類型を特定し、2027年度以降の新制度へ繋げるための要件が整理されました。

### 3. 決定事項
1. **2027年度以降の地上設置型太陽光に対するFITおよびFIP新規支援の原則廃止**
最新のコスト低減状況と市場自立の進展、さらに負の外部経済性の抑制を目的として、地上設置型の事業用太陽光に対する公的支援を廃止する改正法の下位法令が昨年度末に公布されました。これは2027年4月1日より施行される法的決定事項であり、業界にとって最大の市場 inflection point となります。

2. **2027年4月施行を目指した地域共生類型の詳細検討プロセスの開始**
地上設置支援の廃止と引き換えに、2027年度以降も重点的に支援を継続すべき「地域共生型」の具体的な要件定義に着手します。屋根設置、営農型、インフラ空間活用などの類型について、地域への寄与度や導入ポテンシャルに基づき、2026年度末までに算定委員会で具体的な支援価格や期間が策定される合意がなされました。

3. **2026年4月開始の設置状況報告制度とインセンティブ制度の峻別**
2026年4月1日から施行される改正省令により、事業者が工場等の屋根への導入状況や余地を国に報告する義務を負うことが確定しました。これは2025年度下期から開始される初期投資支援スキームという「促進策」とは性質を異にする「規制的義務」であり、企業には適正な情報管理と目標設定が法的に求められます。

### 4. 今後のタイムライン
1. **地方自治体および事業者団体からの重点化類型に関するヒアリング**
2026年7月から8月にかけて実施されます。支援を継続すべき候補類型を選定するため、現場の実務上の課題や地域共生の実現可能性について幅広く意見を集約し、類型の選定基準を明確化します。

2. **支援重点化類型の選定と検討結果の整理公表**
2026年9月頃を予定しています。ヒアリング結果と政策的整合性を踏まえ、2027年度以降のFITおよびFIP制度において重点的に公金が投じられるべき太陽光発電の類型が確定されます。

3. **調達価格等算定委員会における具体的制度設計と論点検討**
2026年10月から2027年1月にかけて深掘りされます。選定された類型ごとに、事業性を担保しつつ国民負担を抑えるための認定基準、支援価格、支援期間、FIP移行の是非といった詳細な制度設計が詰められます。

4. **改正法令のパブリックコメント実施と2027年4月の一斉施行**
2027年2月から3月にかけてパブリックコメントを実施し、再エネ特措法の下位法令やガイドラインの最終改正を行います。これら一連の抜本的見直しは2027年4月1日に一斉施行され、日本の再エネ市場は新たなフェーズに移行します。
