# 日本の供給力確保に向けた政策動向と制度設計の展望

### 1. ポッドキャスト解説ガイド（内容のポイント）

日本の電力需給は、カーボンニュートラル実現に向けた電源構成の転換という極めて重要な過渡期にあります。供給計画上の数字以上に、老朽火力の急激な休廃止や需要変動といった「不確実性」が安定供給を脅かすリスクとして顕在化しており、従来の市場原理だけでは対応しきれない局面を迎えています。本資料では、容量市場を軸とした既存の枠組みに、予備電源制度等の重層的な安全網をいかに組み込み、過渡期の「空白」を埋めるべきか、最新の政策動向に基づき解説します。

* **電力需給見通しの厳格化と不確実性の正体**
発電事業者の供給計画には、地元の調整や経営判断が未定の休廃止計画が反映されにくいという構造的課題があります。実際、2026年度供給計画では、年度内に休廃止される火力電源371万kWのうち、約34％に相当する126万kWが同年度の計画で初めて計上されました。こうした「直前まで見えないリスク」に対応するため、従来の確率論的評価（EUE）に加え、ステークホルダーが直感的に理解しやすく、実需給断面の運用と整合する「確定論的評価（予備率3％基準）」を併用した厳格な評価の必要性が強調されています。

* **既存電源の最大限活用と予備電源制度の安全網機能**
市場価格の下落や競争激化により、維持が困難となった電源の早期退出を食い止めるため、容量市場を補完する「予備電源制度」が創設されました。これは、大規模な電源脱落や想定外の需要増に備え、休止電源を維持・確保し、必要時に立ち上げる枠組みです。特に、容量市場のメインオークションが終了している実需給年度（2030年度まで）における需給逼迫を防ぐための「最後の砦」として位置付けられています。

* **電源の新陳代謝と脱炭素化への円滑な移行**
2030年度以降は「長期脱炭素電源オークション」によるリプレース電源の稼働が需給改善に寄与すると期待されています。しかし、新設には長いリードタイムを要するため、それまでの過渡期を乗り切るには、既存火力を最大限活用しつつ、投資回収の予見性を高める必要があります。単なる設備の延命ではなく、効率的な電源への更新を促すインセンティブ設計と、安定供給維持のバランスが戦略的要諦となります。

### 2. 主要な議題

* **将来の供給力不足リスクの定量的評価手法**
供給信頼度の基準超過が懸念される中、多くのステークホルダーにリスクを可視化するため、「確定論的評価」の導入が議論されています。これは、厳気象H1需要に対する予備率3％という直感的な指標を用いることで、実需給断面での管理との親和性を高めるものです。不確実な需要増減や、供給計画に現れない電源の稼働状況をどの程度シナリオに織り込むべきかが焦点となっています。

* **休廃止検討電源の維持に伴う社会的コストと経済性**
電源の維持には固定資産税や人件費、修繕費などの社会的コストが伴います。2029年度までは予備率が3％を下回るエリアが存在する一方、過剰な設備維持は国民負担を増大させます。燃料種ごとの特性（経年、経済性、環境政策の影響）を踏まえ、いかに必要最小限のコストで効率的に供給力を確保するか、経済効率性と安定供給のトレードオフが検討されています。

* **容量市場の在り方と電源投資の予見性確保**
2031年度以降のメインオークションに向けて、小売電気事業者の負担軽減と、発電事業者の「投資の予見性確保」の両立が急務です。指標価格（NetCONE）の水準や上限価格の設定を抜本的に見直し、電源の新陳代謝を促すインセンティブ構造を再構築することが、将来的な供給力不足を防ぐための鍵として議論されています。

### 3. 決定事項

1. **予備電源制度の詳細な運用ルールの確立**
広域機関が実施主体となり、火力電源を対象とした総合評価方式（価格評価＋技術評価）による公募プロセスが合意されました。価格評価は容量市場の上限価格平均（約14,860円/kW）を目安とし、落札電源の応札価格が約定価格となるマルチプライス方式が採用されます。

2. **電源種別のリクワイアメントと燃料費精算ルールの策定**
予備電源は、実需給まで3ヶ月程度で立ち上げる「短期立ち上げ」と、調達オークション等を経て対応する「長期立ち上げ」に区分されます。特に石油火力については、事前に燃料を確保するための「燃料関係費用」の応札価格への算入を認める一方、制度適用終了後に残った燃料を転売・売電して得た収益の9割を還付する精算ルールが決定されました。

3. **短期供給力確保策の柔軟な運用方針**
メインオークションが終了済みの2030年度までの期間に対し、予備電源の活用や、既に制度化が進んでいる短期供給力確保策（kW公募）の募集量・要件を工夫する方針が示されました。これにより、実需給の直前だけでなく、一定の時間的余裕を持って機動的に供給力を確保する体制を整えます。

4. **非効率石炭火力のフェードアウト誘導措置の導入**
カーボンニュートラルとの整合性を図るため、設計効率42％未満の石炭火力を対象に、実需給年度の設備利用率が50％を超える場合、容量確保契約金額を20％減額する措置が導入されました。これにより、安定供給を維持しつつ、低効率電源の稼働抑制と計画的な退出を促します。

### 4. 今後のタイムライン

1. **2026年度供給計画に基づく需給見通しの精査と提示**
広域機関は、2026年3月末に取りまとめられた供給計画をベースに、専門的見地から事業者の経営判断未定な休廃止リスクや原子力の稼働不確実性を加味した、今後10年程度の電力需給見通しを政策議論の基礎情報として提示します。

2. **予備電源制度のガイドライン改定と公募の進展**
2024年8月のガイドライン策定を起点とし、2025年8月、2026年と段階的な改定プロセスが進められます。これに基づき、短期立ち上げ電源等の具体的な確保プロセスが進行し、実際の電源確保に向けた募集要綱の公表と応札が実施されます。

3. **第7次エネルギー基本計画の閣議決定と制度の具体化**
2025年（令和7年）2月の閣議決定を踏まえ、2031年度以降の容量市場の抜本的見直しや、既存火力の最大限活用に向けた更なる詳細な制度設計がワーキンググループで検討されます。特に「投資の予見性確保」と「国民負担抑制」の観点から、長期脱炭素電源オークションとの整合性を含めた議論が本格化する見通しです。
