# GX需要創出に向けたGX率先実行宣言の見直し方針（中間とりまとめ）の解説

### 1. ポッドキャスト解説ガイド（内容のポイント）
成長志向型カーボンプライシング構想の進展に伴い、「GX率先実行宣言」は定性的な努力目標から、定量的な証明を必須とする実効性の高い制度へと抜本的に刷新されました。企業の需要創出への貢献度を「定量的な閾値」で厳格に評価し、GX関連予算の加点措置と直接連動させることで、GX投資の市場価値を正当に評価する新たなフェーズへと移行します。

* **プラチナグレードの創設による評価の厳格化**
従来の定性的な「ブロンズ・シルバー・ゴールド」評価は廃止され、国の目標に準じた極めて野心的な「プラチナグレード」が新設されました。現行の「ゴールド」取得企業であっても、新たな定量基準を満たさない限りプラチナへの自動移行は認められず、真に需要創出に寄与する希少な企業群のみを厳選・公表する仕組みとなります。

* **客観的な定量閾値（A・B・C要件）の導入と中央値（1.0%/0.9%）の論理**
評価軸として、政府・業界目標（A）、排出削減率1.0%以上（B）、売上原価比0.9%以上の投資（C）が設定されました。特にBとCの数値は、水素やSAF、グリーンスチール等、先行9製品の試算結果における「中央値」を採用しており、Aの政府目標と同等以上の野心度を担保する科学的な根拠に基づいています。

* **GX予算採択における「前提要件」と「加点措置」の峻別**
令和8年度予算から、中小企業を除き「GXフューチャー・リーグ」への入会がGX予算申請の必須要件（前提）となります。その上で、「プラチナグレード」の取得は採択審査における有力な「加点要素」として機能し、担当課の判断による補助率のかさ上げなど、直接的な経済的インセンティブに直結します。

* **実事業との連動を担保する「ポジティブリスト制」と「GXスチール」の先行適用**
「グリーンウォッシュ」を排除するため、業種別の排出源に基づき自社努力で削減可能な製品を定めた「ポジティブリスト」からの選択が義務化されます。特に「グリーンスチール」は、2026年3月に策定されたGHG排出削減実績量ガイドラインと整合した初の対象製品として位置づけられ、実事業との関連性が厳格に問われます。

### 2. 主要な議題
* **現行制度における定量的な「貢献の物差し」の不在**
従来の最上位であるゴールドグレードにおいても明確な調達量の閾値が存在せず、企業の需要創出に対する実質的な貢献度を客観的に比較・評価できなかった構造的課題が、見直しの最大の論点となりました。

* **供給側視点の製品区分による「調達側の認識不全」**
対象製品が供給側の技術視点で分類されていたため、調達側の企業にとって対象範囲や削減インパクトの計算が困難であり、初期需要の立ち上げを阻害していたという認識齟齬の解消が議論の焦点となりました。

* **宣言内容と実事業の乖離およびフォローアップ不足**
自社の主要な排出源とは無関係な製品での宣言が可能であった点や、宣言後の進捗確認体制が未整備であったことが、制度の透明性と対外的な信頼性を損なうリスクとして指摘されました。

### 3. 決定事項
1. **「プラチナグレード」への認定要件と製品単位の公表**
事業活動との関連性（ポジティブリスト選択）、定量閾値（A・B・C）の充足、定量的貢献評価の3要素を必須化します。認定状況はGX推進機構のHPにおいて、企業単位ではなく「製品単位」で詳細に列記・公表され、市場からの視認性を極限まで高めます。

2. **試算に基づくB・C閾値の代替適用ルール**
政府目標（A）が未設定の製品については、1.0%（B）または0.9%（C）を代替基準として適用します。これはAを達成した場合のインパクトを先行9事例でシミュレーションし、その中央値を採用することで、どの基準を選んでも同等の野心度が維持される設計となっています。

3. **GX予算連動における「事業特性」に応じた加点適用**
「特定の製品調達に限定される事業」では当該製品のプラチナグレード取得を条件に加点し、「限定されない事業や委託事業」では製品を問わずプラチナ取得をもって加点する二段構えの評価体制を構築します。これにより、予実管理と連動した予算執行を実現します。

4. **「フォローアップ会合」の実施とグレード取消規定**
事務局による年1回のヒアリング（フォローアップ会合）を導入します。回答拒否や宣言内容の著しい不履行が確認された場合には、プラチナグレードの取り下げや取消しを断行する厳格な運用体制を構築し、制度の信頼性を死守します。

### 4. 今後のタイムライン
1. **2026年秋頃：新制度に基づく募集・認定の開始**
中間とりまとめを踏まえたマニュアル整備、システム改修、企業向け説明会を順次実施し、秋頃を目途に新たな定量基準によるプラチナグレードの募集・認定を開始します。

2. **2026年度（令和8年度）：GX関連予算との実運用連動**
令和8年度予算の採択審査において、GXフューチャー・リーグ入会の要件化と並行し、プラチナグレード取得企業への加点措置を速やかに適用開始します。

3. **2027年春頃：閾値の妥当性検証と「上方修正」の検討**
運用開始半年後の実績を分析し、特にB・Cの基準がAに対して甘いと判断されたり、B・Cルートが主流化して野心度が低下したりした場合には、速やかに閾値を「引き上げる」などの制度改善を断行します。

4. **2027年度：表彰制度の創設に向けた具体的議論**
プラチナグレード取得企業の中でも特に優れた需要創出への取組を行う企業を評価するため、具体的な表彰制度やさらなる評価基準の議論を継続し、2027年度中の制度開始を目指します。
