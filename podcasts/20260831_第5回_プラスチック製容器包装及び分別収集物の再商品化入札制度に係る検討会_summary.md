# プラスチック製容器包装及び分別収集物の再商品化入札制度に係る検討会（第5回）結果報告

### 1. ポッドキャスト解説ガイド（内容のポイント）

2026年8月31日に開催された第5回検討会は、日本のプラスチック資源循環の転換点となる令和10年度（2028年度）の新制度施行に向け、実務レベルの骨子を固める極めて重要な場となりました。材料リサイクル事業者の深刻な収益性悪化という「動脈」の課題に対し、複数事業者による「ジョイントグループ」での再商品化、高品質再生材の供給を支える「新枠」の創設、さらにはケミカルリサイクルの評価基準となる油化・モノマー化ガイドラインの改定といった、官民連携による構造的な解決策が提示されています。

*   **材料リサイクル事業者の経営実態と高品質化への課題**
    実態調査により、材料リサイクル事業者の収益性が極めて深刻であることが浮き彫りとなりました。一般的な製造業の黒字企業平均（TKC経営指標）が4.9%であるのに対し、入札価格が高位な事業者の多くは、現行の上限価格を適用すると営業利益率が5%未満（大半は0%未満の赤字）に沈みます。興味深いのは、入札価格高位層は17〜80基の高度な設備を保有して高品質化に挑んでいるのに対し、低位層は9基程度に留まっている点です。投資を行っている事業者ほど、未成熟な再生プラ市場によるコスト転嫁の困難さに直面し、「収益化の壁」に阻まれている実態がデータから裏付けられました。
*   **令和10年度以降の複数事業者によるジョイントグループ登録**
    令和10年度より、1つの代表事業者と複数の構成事業者による柔軟なジョイントグループ登録が解禁されます。特筆すべきは、異なる技術手法を公正に評価する「等価的統合収率」の導入です。これは、材料リサイクルの基準（45%）をベースに、各ケミカルリサイクル手法の基準値との比率（係数）を乗じて算出する仕組みで、技術中立的な評価を可能にします。これにより、1事業者では困難だった高度選別と多様なリサイクル手法の組み合わせが促進され、システム全体の最適化が図られます。
*   **高品質再生材の供給を促進する「新枠」の創設**
    水平リサイクルを強力に推進するため、「特定高品質再生材供給推進枠（新枠）」が創設されます。この枠では、選定された事業者に最長5年間の優先的な落札権が付与されるインセンティブが設けられます。ただし、この優先権は「一度落札すれば安泰」というものではなく、毎年の「新枠評価方式委員会」による進捗確認（フローチェック）をパスし、かつ前年度と同量・同額での入札を行うことが維持の厳格な条件となります。
*   **油化およびモノマー化に係るガイドラインの改定**
    従来の燃料用途に加え、プラスチック原料として利用される炭化水素油を得る「原材料用途」の収率基準が新設されます。PS（ポリスチレン）モノマー化については、生成物が液体炭化水素であるため油化と同様に整理されますが、高度な選別を要することから「ジョイントグループの構成事業者としての活用」が基本方針とされました。一方で、PETモノマー化については、生成物が固形である等の理由から現時点での基準設定は困難であり、今後の継続検討課題とされています。

### 2. 主要な議題

*   **再商品化入札における上限価格の妥当性と事業継続性**
    入札価格の上昇傾向と上限価格適用の常態化は、事業者の赤字リスクを恒常化させ、設備更新の停滞や新規参入の阻害を招いています。適切な上限価格の設定は、単なるコスト議論ではなく、日本のリサイクル処理能力の逼迫を防ぎ、資源循環インフラを維持するための安全保障上の課題として分析されています。
*   **高品質再生材の初期需要創出とコスト転嫁のメカニズム**
    新枠の成功には、特定事業者（最終製品製造事業者）との緊密な連携が不可欠です。中東情勢の不安定化に伴う石油資源の価値変動や、質の低いリサイクルであるカスケード利用とのバランスを注視しつつ、高品質再生材に伴う追加負担をサプライチェーン全体で分かち合う、マクロな視点に立った需要創出メカニズムの構築が議論されました。
*   **リサイクル手法の多様化に伴う技術中立的な評価基準の確立**
    材料リサイクル、油化、モノマー化などの異なる手法を「等価的」に評価するための基準設定が焦点です。各手法の歩留まりや環境負荷の差異を科学的に評価しつつ、特定の技術に偏らない公正な競争環境をいかに構築するか。資源循環の「質」を最大化するためのデジタルな管理手法の導入を含め、評価基準の精緻化が進められています。

### 3. 決定事項

1.  **ジョイントグループにおける「等価的統合収率」の導入**
    材料リサイクル（基準45%）を軸に、他手法の基準（例：コークス炉85%）との比率を用いて算出する「Zeq≧45%」を施設審査の合格基準とします。支払金額の算出においても、等価換算した収率上限「Yeq=50%」を適用し、手法の組み合わせに左右されない一貫した報酬体系を確立します。
2.  **「特定高品質再生材供給推進枠」の運用要件と評価方式**
    日本容器包装リサイクル協会内に「新枠評価方式委員会」を設置し、複数年の製造・販売計画に基づき事業者を選定します。落札後の優先権維持には、毎年の進捗確認（フローチェック）の合格と、前年度と同量・同額での入札を必須条件とすることで、計画の確実な履行を担保します。
3.  **油化手法における原材料用途の収率基準新設**
    再生処理ガイドラインを改定し、燃料用途とは別に、化学工業等で原材料（ナフサ代替等）として利用される炭化水素油の基準を新設します。これにより、PSモノマー化（ジョイントグループ前提）を含めたケミカルリサイクルの高度利用を、制度的に明確な「再商品化」として位置づけます。

### 4. 今後のタイムライン

1.  **令和8年度（2026年度）内のモデル事業実施と詳細検討**
    ジョイントグループによる再商品化の品質・収率・コストを検証するモデル事業を2027年2月まで実施します。この成果と第4回検討会以降のコメントを反映し、第6回検討会を通じて新枠の詳細な運用案を確定させます。
2.  **令和9年度（2027年度）における準備と運用公表**
    新枠および複数ジョイントの具体的な運用ルールを公表し、事業者の準備期間を確保します。令和10年度入札に向けた「新枠評価方式委員会」を立ち上げ、申請受付と計画の厳格な事前評価を開始します。
3.  **令和10年度（2028年度）からの新枠および複数ジョイント本格稼働**
    当初3万トン規模からスタートする「新枠」の入札を開始します。同時に、1代表事業者と複数構成事業者、あるいは1事業者内複数施設によるジョイントグループの登録・運用を全面的に稼働させ、新たな資源循環体制へ移行します。
