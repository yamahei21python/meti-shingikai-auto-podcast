# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
中東情勢（ホルムズ危機）の緊迫化に伴うエネルギー供給の不確実性の高まりを受け、わが国のエネルギー安全保障は再定義を迫られています。今回の小委員会では、GX（グリーントランスフォーメーション）を強力に推進することで、原子力や再生可能エネルギーなどの脱炭素電源比率を2040年度に最大7割程度まで引き上げる目標が示されるとともに、需要側での省エネ・非化石転換を加速させ、化石燃料への依存を徹底的に低減するための具体的な施策が議論されました。

* **中東情勢を踏まえた需要側の強靭化**
原油の中東依存度が高いアジア諸国において供給懸念が顕在化する中、日本は需要側での強靭化を推進します。従来の省エネに加え、再エネ活用や電化、燃料転換を一体的に進めることで、外部環境の変化に強い需給構造への転換を図ります。

* **GX予算（約6,000億円規模）の戦略的活用**
令和7年度補正予算で措置された約6,000億円規模の予算や、総額2,450億円にのぼる省エネ・非化石転換補助金を最大限に活用します。これにより、初期費用が数百億円に達する大規模投資や、家庭での断熱窓・高効率給湯器の導入を強力に支援し、経済成長と脱炭素化を両立させます。

* **AI・デジタル技術による非連続な省エネの創出**
データセンターのエネルギー効率に関する報告義務の拡充や、AI制御による性能向上（約15％の効果）を見込んだ設備の導入を促します。「デジタル・AI省エネ手引き」の活用を通じ、最新技術を用いた非連続な省エネルギー効果の創出を目指します。

* **支援（GXⅢ類型）と規制（トップランナー制度）の一体的な推進**
新たな補助枠「GXⅢ類型（トップ性能枠）」で初期需要を創出し、普及率の高まりに応じてトップランナー制度等の規制を適用することで、自立的な市場形成を狙います。普及率に応じた支援強度の適正化を図り、最終的な一般化（補助金卒業）に向けたロードマップを明確化します。

### 2. 主要な議題
* **供給不確実性への対応とエネルギー需給構造の強靭化**
中東情勢の影響を強く受ける日本の現状を踏まえ、需要側が実施すべき「1段階上の取組」が焦点となりました。単なる合理化に留まらず、電化や燃料転換による化石燃料依存の低減をエネルギー安全保障の根幹として位置づけ、その加速策が議論されました。

* **「GXⅢ類型（トップ性能枠）」の創設と新設投資への拡大**
トップランナー性能を凌駕する革新的設備を支援する新枠の創設が提案されました。設備更新時の補助率を1/3から1/2に引き上げるだけでなく、これまで対象外であった「新設」についても補助対象（補助率1/5）に含めることで、投資を強力に誘発する方針が検討されました。

* **老朽化設備（30年以上経過が20％）の更新と産業競争力**
導入から20年以上経過した設備が35％、30年以上が20％に達しており、老朽化が進んでいる現状が報告されました。数百億円規模の大型投資を伴う高効率ガスタービンやコジェネレーションへの更新を促すことが、日本の産業競争力維持と脱炭素化の鍵であるとの認識が示されました。

* **ベンチマーク制度の定義移行と停滞事業者（Bクラス）への法的対応**
省エネ取組が5年度以上にわたり停滞しているBクラス事業者に対し、省エネ・非化石転換法に基づく合理化計画の作成指示等の厳格な法的対応を行う必要性が議論されました。また、ベンチマーク指標のエネルギー定義や換算係数を、順次新法の体系に移行する方針が示されました。

### 3. 決定事項
1. **2026年夏季の省エネルギー呼びかけと広報展開**
国民経済や生活に支障のない範囲での省エネを求めることが決定されました。広報にあたってはナッジ的手法を活用し、世帯あたりの電気・ガス・ガソリン代の具体的な削減効果を提示することで、国民の納得感を得ながら行動変容を促す方針が確認されました。

2. **令和7年度補正予算（約6,000億円規模）の最大活用**
令和7年12月に成立した補正予算を最大限活用し、企業の設備投資や家庭の省エネ化を加速させることが確定しました。特にサプライチェーン連携（4者以上）による申請枠や、水素対応設備への改造支援の拡大などを通じて、支援の裾野を広げます。

3. **三相誘導電動機判断基準ワーキンググループの設置とIE4普及加速**
本小委員会の下に専門のWGを設置し、IE4モータを念頭に置いた新基準の検討を開始することが決定されました。IE4化により原油換算で約635万kL（約285億kWh）の省エネポテンシャルがあることを踏まえ、GXⅢ類型による支援と規制を一体的に運用します。

4. **データセンターのエネルギー効率提示および報告義務の拡充**
データセンター事業者が満たすべきエネルギー効率の提示を行うとともに、報告義務の内容を拡充することが決定されました。さらに、一部の情報の可視化を進めることで、透明性の高い評価制度を構築し、デジタルインフラの効率化を推進します。

### 4. 今後のタイムライン
1. **2026年6月以降、IEAの「政策対応トラッカー」による国際発信**
IEAのデータベースを通じ、日本の夏季省エネ呼びかけ等の政策を随時発信します。①需要抑制策、②消費者支援策、③構造転換策の3つのカテゴリーに基づき、他国の動向を注視しながら、日本のエネルギー危機対応を国際的に提示し続けます。

2. **2027年以降、補助金卒業に向けたソフトランディング枠の検討**
省エネ性能の高い設備の普及率向上に合わせ、支援の強度を段階的に適正化させる「従来型Ⅲ類型（卒業準備）」の追加を2027年以降に検討します。これにより、補助金に依存しない自立的な市場の一般化を段階的に図ります。

3. **2028年末までに、中国の3カ年計画を踏まえたベンチマーク評価**
中国が発表した鉄鋼、アルミ、セメント、石油精製、石炭火力発電等を含む計9業種の省エネ3カ年計画も考慮しつつ、日本においても鉄鋼等8業種でのベンチマーク達成状況を2028年末までに評価します。必要に応じて指標や水準の抜本的な見直しを行います。

4. **2040年度、脱炭素電源比率最大7割に向けた第7次エネルギー基本計画の着実な実行**
令和7年2月に閣議決定された「第7次エネルギー基本計画」に基づき、2030年度目標の完遂と2040年度に向けた構造転換を進めます。省エネを脱炭素への第一歩と位置づけ、非連続な技術開発と電化・燃料転換を計画的に推進します。
