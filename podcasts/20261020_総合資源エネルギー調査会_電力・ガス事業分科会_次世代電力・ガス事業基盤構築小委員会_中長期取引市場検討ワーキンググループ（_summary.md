# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
第5回中長期取引市場検討ワーキンググループ（2026年10月20日開催）では、「市場参加者」「取り扱う商品」「市場範囲・市場分断リスクへの対応」に関する制度詳細の検討が行われました。計画値同時同量義務を負う実物電力を扱う事業者の安定調達と発電事業者の投資予見性向上を目的とし、市場流動性の確保と買占め防止のバランスを踏まえた詳細な制度設計の方向性が示されています。

* **市場参加者の限定と転売・購入量上限の設定**
当面の市場参加者は計画値同時同量義務を負う電気事業者（発電事業者および小売電気事業者）に限定し、自ら売買を行うトレーダー事業者の参加は見送る方針が整理されました。需要変動等に対応した小売電気事業者の転売（売り入札）を認める一方、特定事業者による買占め防止および小売供給に必要な範囲（受渡年度の需要量・過年度販売実績量）への適正化を図るため購入量上限を設定する考え方が示されました。

* **3年前商品におけるミドル商品の追加設定**
想定需要の5割にあたる供給力確保義務を3年前時点でベース商品のみで達成することは負荷率の観点から困難である実態を踏まえ、調達選択肢の拡大と供出機会の確保を狙いとして、事後調整付および事後調整のないミドル商品を3年前1年物商品にも追加設定する方針が決定されました。

* **市場範囲の設定と値差リスクへの対応**
過度な値差リスクを回避しつつ市場の流動性と匿名性を維持するため、市場開設直前の連系線工事や需給動向を反映して具体的な市場範囲を確定する方針が確認されました。また、相対・OTC市場で流動性が拡大しているエリアスプレッド取引や、新電力の参加が進む電力先物等の既存ヘッジ手段を活用する実務的方針が示されました。

### 2. 主要な議題
* **市場参加者の範囲と転売および購入量上限の取扱い**
実物電力を扱う電気事業者を優先する観点から、単なるトレーダー事業者の参加可否や、小売電気事業者による転売の容認、過年度販売実績量等を基準とする購入量上限の設定が議論されました。上限算定にあたっては、複数事業者による共同調達時の合算需要に基づく一体評価や、実績のない新規登録事業者の取扱いが論点となりました。また、発電事業者による電源差替買い入札について、小売電気事業者の供給力アクセス確保と市場流動性への影響を天秤にかけた検討が行われました。

* **3年前における取り扱い商品（ミドル商品）の検討**
3年前の時点でベース商品のみでは負荷率の観点から供給力確保義務の達成が難しいとの実務上の意見を踏まえ、供出可能な発電事業者の機会確保と小売電気事業者の調達手段拡大を目的として議論されました。従来1年前商品のみに求められていたミドル商品（事後調整付／事後調整なし）について、3年前1年物商品においても市場運営者に最低限設定を求める商品に追加することが検討されました。

* **複数市場における市場範囲の画定基準と値差ヘッジ手段**
エリア間の分断値差発生率や値差の大きさを踏まえた市場範囲の画定基準について論議されました。ベースロード市場の指標（直近1年間の分断値差発生率平均30%以上または30%超が6ヶ月以上かつ年間平均値差1.5～2.0円/kWh以上）等を参考に判断基準を定めることや、開設直前の状況に基づく範囲確定が議論されました。さらに、相対・OTCで一般的となり流動性が増加しているエリアスプレッド取引や、大手新電力を除く新電力143者が参加する（2026年7月時点）東京商品取引所等の電力先物取引の活用可能性が検証されました。

### 3. 決定事項
1. **当面の市場参加資格の限定**
計画値同時同量義務の主体であり実物電力を扱う電気事業法上の電気事業者（発電事業者および小売電気事業者）等に市場参加者を限定し、現段階では自ら売買を行う単なるトレーダー事業者の参加は見送ることが決定されました。

2. **小売電気事業者の転売容認と購入量上限の基準**
需要変動等に対応するため購入済み商品の転売（売り入札）を認める一方、特定事業者による買占めを防ぎ小売供給に必要な範囲に制限するため、受渡年度の需要量（過年度販売実績量等）を購入量上限（買い入札量および約定量上限）とすることが決定されました。共同調達の場合は合算需要で一体評価し、新規登録事業者や転売後の上限管理は別途整理することとされました。

3. **3年前商品へのミドル商品の追加設定**
市場運営者に最低限設定を求める商品として、従来の1年前商品に加え、3年前1年物商品においてもベース商品と併せてミドル商品（事後調整付商品および事後調整のない商品）を追加設定することが決定されました。

4. **市場範囲の確定時期と見直し方針**
市場開設時の具体的分断範囲は、連系線工事や需給動向に伴う最新の値差発生状況（分断率）を反映するため市場開設直前の状況を踏まえて確定し、開設後も定期的に検証を行って市場範囲の統合や細分化を柔軟に見直す方針が合意されました。

### 4. 今後のタイムライン
1. **市場開設直前における市場範囲の確定**
連系線の工事状況や供給・需要動向を反映した最新の値差発生状況（分断率）や値差の大きさを評価し、中長期取引市場の開設直前に具体的な市場範囲（市場の個数や境界）を確定します。

2. **開設後1年間の運用状況評価と最低供出割合の検討**
市場開設後、負荷パターン別の売買入札量、約定量、調達ニーズを1年間にわたり継続的に確認し、需要がある商品への供出不足が生じる場合には、発電事業者の供出可能性を考慮した最低供出割合の導入を検討します。

3. **市場範囲の定期的な検証と見直し**
市場開設後においても、スポット市場等におけるエリア間値差の発生状況やその推移を定期的に検証し、許容できる値差リスクや市場流動性に応じて市場範囲の統合や細分化等の見直しを継続的に実施します。

4. **約定状況等を踏まえた市場参加者範囲の再検討**
市場開設後の実際の約定状況、売買気配の厚み、転売の実施状況などを精査した上で、市場機能の向上や流動性確保に向け、将来的な市場参加者範囲の見直しを再検討します。
