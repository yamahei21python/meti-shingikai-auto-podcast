# 第七回 CCS事業の支援措置に関するワーキンググループ分析レポート

第7回「CCS事業の支援措置に関するワーキンググループ」の審議資料および中間とりまとめ（原案）に基づき、2030年までの事業開始を目指すCCS制度設計の最前線を分析します。本レポートでは、現段階で詳細が確定したパイプライン案件向けの支援策を軸に、ファイナンス面のリスク緩和措置や事業者の義務規定を構造化して整理します。

### 1. ポッドキャスト解説ガイド（内容のポイント）

*   **導入文**
    政府は2030年までのCCS事業開始を確実にするため、現時点ではパイプライン輸送案件を主な対象として、CCSコスト（基準価格）と炭素価格（参照価格）の差分を補填する「コスト差支援措置」の具体案を提示しました。本制度は、15年間の支援期間と10年間の事業継続義務をパッケージ化し、EPCコストの上振れリスクや他プロセスの停止に伴うクロスチェーンリスクへの金銭的救済策を盛り込むことで、民間事業者の投資予見可能性を最大化することを目指しています。

*   **15年間の支援と10年間の事業継続義務のセット**
    事業の自立化に向けた市場形成には時間を要することから、支援期間は15年間に設定されました。一方で、公的資金投入の対価として、支援終了後も10年間の事業継続が義務付けられます。特筆すべきは、分離回収事業者に対し、物理的なCCSの継続が困難な場合の「脱出条項」として、実削減を伴う他の排出削減取組による代替（サブスティテューション）が認められた点であり、長期的な事業リスクを緩和する重要な戦略的選択肢となります。

*   **コスト差支援（基準価格ー参照価格）の論理**
    支援額は、適正性審査を経たCCS総コスト（基準価格）から、排出事業者が本来負担すべきCO2対策コスト（参照価格）を差し引いて算出されます。参照価格は、排出量取引制度（GX-ETS）における市場価格の平均を基本とし、特定のベンチマークに依存しない実態に即した設定となっています。これにより、炭素価格の低迷期においても事業者のキャッシュフローを安定させる機能を果たします。

*   **クロスチェーンリスクへの政策的対応（支援延長や先払い）**
    分離回収、輸送、貯留のいずれかで生じた停止が連鎖するリスクに対し、事業者の責めに帰さない事由であれば支援期間の延長が認められます。さらに、他社の不具合により自社の操業が止まりキャッシュフローが枯渇する場合、延長期間に受け取るべきCAPEX相当分を「先払い」する措置が導入されました。これは、プロジェクトファイナンスの組成において懸念されるデットサービス能力の維持に直結する強力な救済策です。

*   **包括的な総合評価による案件選定**
    コストの低廉性のみならず、事業計画の全体像を評価する「総合評価」が導入されます。具体的には、実施体制の妥当性や資金調達の確実性に加え、将来的なコスト低減の見込みや地域社会との受容性形成、さらには労働者の安全確保など、多角的な項目による選定が行われます。これにより、単なる安値入札ではなく、2030年までの確実な稼働開始が見込める案件が優先されます。

### 2. 主要な議題

*   **支援対象案件の選定における総合評価項目の具体化**
    支援対象を選定する際、基準価格の適正性審査と併せて、事業計画の妥当性を評価する具体的な項目が議論されました。スケジュールや体制、資金調達の目途に加え、エネルギー政策やGXの取組方針との整合性、技術革新による将来の自立化可能性などが評価の柱として据えられています。

*   **分離回収・輸送貯留それぞれのコストに含まれるべき費目の妥当性**
    CCSバリューチェーンの各工程で発生するCAPEX（建設費、プロジェクト管理費等）およびOPEX（運転維持費、保険料等）のうち、支援対象として認めるべき範囲が精査されました。特に輸送貯留側では、廃坑費やモニタリング費などの将来費用について、支援期間（15年）と継続義務期間（10年）の比率に基づき、総額の15/25のみを支援対象とする算定論理が導入されました。

*   **排出量取引制度（GX-ETS）の価格を基本とする参照価格の考え方**
    事業者のカーボンニュートラル達成手段が多様であることを背景に、参照価格を一律の固定値ではなく、GX-ETSの市場価格に連動させる方針が焦点となりました。これにより、市場における炭素価格の変動を制度内に取り込み、政府・事業者間での適切なリスク分担を図ります。

*   **長期脱炭素電源オークションとの重複排除**
    電力分野の案件において、長期脱炭素電源オークションによる支援と本制度が二重に適用されないよう、支援範囲の整理が行われました。オークションでカバーされる固定費や可変費については、本制度の基準価格の算定から除外することで、政策資金の効率的な配分を徹底します。

### 3. 決定事項

1.  **基準価格の算定式（A1, A2, B1等の変数定義）**
    トン当たりの基準価格を算出する数式が確定しました。電力・燃料費等の変動費（A1, α1）、物価連動の維持費（A2, α2）、物価変動を受けない維持費（A3）、建設費総額（B1）、運転開始前費用（B2）、資金調達コスト（C）を組み合わせ、総貯留想定容積で除します。ここでB1には110%以下の係数が掛けられ、予備費の枠組みを数式内で担保しています。

2.  **CAPEXの最大10%を予備費として認める運用**
    EPCコストの上振れや地下の不確実性に対応するため、建設費の10%を上限に予備費を計上できるリスクバッファー機能が明文化されました。ただし、リスクが顕在化せず未使用となった予備費の一部は、事後的に基準価格から控除され、過度な支援を抑制する調整メカニズムが備わっています。

3.  **建設費の75%を上限とする先行支援の導入**
    初期投資負担を軽減し、金融コストを抑制するため、建設費相当分の最大75%を操業開始前に交付する先行支援が導入されました。この措置はキャッシュフローの改善を通じてプロジェクト全体の支援額縮小に寄与することを条件としており、輸送貯留事業者に対しても直接交付が可能な簡素な実務体系となっています。

4.  **支援終了後10年間の事業継続義務および違反時の返還規定**
    15年間の支援終了後、さらに10年間の事業継続が法的に義務付けられました。義務違反時には帰責性に応じた支援金の返還が求められますが、分離回収事業者については、物理的なCCSに代えて「実削減を伴う排出削減の取組」を実施することで義務を履行できる代替ルール（代替可規定）が確定しました。

### 4. 今後のタイムライン

1.  **2026年3月からのCO2カウントルールの議論開始（算定方法検討会）**
    CCSによる削減量を国内制度でどのようにカウントするかを定めるため、温室効果ガス排出量算定方法検討会において2026年3月から詳細な議論が開始されます。

2.  **個別のCCSプロジェクトの進捗を踏まえた選定スケジュールの検討**
    2030年までの確実な稼働を実現するため、先行する各プロジェクトの試掘進捗や詳細設計の状況を勘案し、具体的な案件選定および公募のスケジュールを順次策定します。

3.  **船舶輸送案件向けの支援措置の継続検討（クラスター化や効率化の仕組み）**
    今回の中間とりまとめは主にパイプライン案件を対象としていますが、船舶輸送については排出源のクラスター化や輸送効率化のための共通仕様化を前提に、別途支援措置の在り方を検討し、ビジネスモデルの構築を急ぎます。

4.  **複数年おきに実施される算定式の更新見直し**
    技術革新によるコスト低減や事業環境の変化を制度に反映させるため、固定的な支援に留まらず、複数年ごとに基準価格の算定パラメータを見直す運用が検討されます。
