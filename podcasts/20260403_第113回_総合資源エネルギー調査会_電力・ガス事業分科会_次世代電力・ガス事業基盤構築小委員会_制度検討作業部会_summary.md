# 第113回制度検討作業部会：非化石価値取引の確報値決定と供給力確保策の恒久化への転換

令和8年4月3日に開催された「第113回制度検討作業部会」では、非化石価値取引制度の2026年度目標値の確定、2025年度の緊急代替調達の実施、そして東京エリアの需給逼迫に対応した供給力確保策の抜本的見直しという、電力実務に重大な影響を及ぼす決定がなされました。本レポートでは、審議会資料の背後にある論理と市場へのインプリケーションを専門的視点から分析します。

### 1. ポッドキャスト解説ガイド（実務の要点と分析）

本会合の審議内容は、制度の安定性と実効性を高めるための「精緻化」と、過渡期の危機対応を「恒久化」する仕組みへの移行に集約されます。

*   **2026年度中間目標値（確報値）の14.8％設定と市場の予見性確保**
    2026年度の供給計画を反映し、非化石証書の外部調達比率を14.8％に確定しました。特筆すべきはFIT発電量の推計精度です。過去10年の実績に基づく重回帰分析（多項式近似）により、決定係数 $R^2 = 0.99$ という極めて高い相関性を持った推計式を採用しています。原子力の再稼働反映により外部供出可能量が約1,270億kWhへ増加した一方、目標比率を速報値（12.9％）から引き上げた背景には、前年度（15.0％）と同水準を維持することで、需給バランス1.05を堅持し市場の予見可能性を確保するという政策的意図があります。

*   **2025年度代替調達の発動判断と市場への影響評価**
    事業者アンケート（買手60者、売手20者中55者回答）の結果、2025年度の需給バランスが0.90～0.95と、1を下回る逼迫見通しとなったため、FIT証書による代替調達を認めます。入札条件を非FIT市場上限価格の1.3円/kWh以上に設定した理由は、第3回オークション等で既に上限価格で調達済みの事業者との公平性を維持するためです。なお、代替調達の想定必要量（最大約130億kWh）に対し、FIT市場の売残り推計は約640億kWhと潤沢であり、FIT市場全体の価格高騰を招くリスクは極めて低いと分析されます。

*   **東京エリア「厳気象H1需要」対応の120万kW緊急公募**
    2026年度夏季、東京エリアでは「厳気象H1需要」に対し、安定供給のデッドラインである予備率3％を割り込む極めて厳しい見通しが示されました。これを受け、120万kW規模の追加供給力公募（kW公募）を即時実施します。これは、老朽火力の廃止と新設電源（LNG等）の稼働時期のギャップから生じる構造的な供給力不足を補う緊急措置です。

*   **「新確保策」への移行：託送料金から容量拠出金による費用回収へ**
    これまで暫定的な「kW公募」として実施されてきた追加供給力調達を、容量市場の枠組みに組み込んだ「新たな短期供給力確保策（新確保策）」として恒久化します。最大の変更点は費用負担構造です。従来の「託送料金」による回収から、容量市場の枠組みである「容量拠出金」による負担へと移行します。これは、小売電気事業者が自らの需要に応じた供給力確保義務を負うという原則に立ち返るものであり、新電力各社の財務計画に直接的な影響を及ぼします。

### 2. 主要な議題

*   **非化石証書需給バランスの再評価と目標値の確報化**
    2026年度の最新供給計画に基づき、非FIT供給想定量や需要想定量を更新。速報値からの需給バランスの変化を精査し、義務達成に向けた「外部調達比率」を確定させる論点。
*   **代替調達スキームの適用と既存調達者との公平性確保**
    アンケートに基づく定量的分析により、高度化法義務履行が困難なリスクを特定。非FIT市場の規律を維持しつつ、セーフティネットとしてFIT証書を活用するための適用条件（1.3円入札等）を検討する論点。
*   **容量市場を補完する短期供給力確保策の制度設計**
    実需給1年以内の突発的な不足に対し、一般送配電事業者による暫定措置を、電力広域的運営推進機関（OCCTO）が担う容量市場の一部へと再定義し、恒久的な費用負担の在り方を構築する論点。

### 3. 決定事項

1.  **2026年度外部調達比率を14.8％に決定**
    原子力の再稼働等の織り込みにより外部供出可能量が1,270億kWhに拡大したことを受け、需給バランス1.05を維持する水準として、速報値（12.9％）から1.9ポイント引き上げた確報値を承認した。
2.  **2025年度代替調達の実施および上限単価1.3円/kWhの条件課付**
    需給バランスが1を下回る（0.90～0.95）見込みを確定し、代替調達を認める。公平性確保のため、第4回非FITオークションにおいて必要量を1.3円/kWh以上で入札することを条件とした。
3.  **2026年度夏季東京エリア向け120万kW緊急公募の即時開始**
    予備率3％死守のため、120万kWの募集量を設定。安定供給確保に向けた緊急的な電源確保と、デマンドレスポンス（DR）の活用を促す。
4.  **「新確保策」の制度化に向けた基本方針の承認**
    kW公募を容量市場の補完措置（新確保策）へと移行。費用負担を容量拠出金とする方針を固め、具体的な実務設計をOCCTOに委ねることを決定した。

### 4. 今後のタイムライン

1.  **2026年度中間目標値（確報値）の事業者通知（2026年6月頃）**
    本決定に基づき、対象事業者へ確定した目標値を個別に通知し、義務履行を促す。
2.  **2025年度第4回非FITオークションと代替調達の実行**
    決定された1.3円入札の条件に基づき、代替調達スキームを用いたオークションを実施。
3.  **OCCTOによる「新確保策」の具体的詳細設計**
    容量市場の一部として、電源調達の範囲、期間（月単位・日単位）、ペナルティ、および容量拠出金によるエリア別費用負担の詳細を、電力広域的運営推進機関において加速させる。
4.  **暫定措置（kW公募）から恒久制度（容量市場補完策）への完全移行**
    東京エリアの120万kW公募を実務上の最終的な試金石としつつ、2026年度以降の突発的需給逼迫に対応する新たな供給力確保スキームの運用を開始する。
