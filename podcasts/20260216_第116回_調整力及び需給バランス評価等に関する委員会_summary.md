# 第116回 調整力及び需給バランス評価等に関する委員会 詳細レポート（2026年2月16日開催）

### **ポッドキャスト解説ガイド（内容のポイント）**

本セクションでは、電力インフラの安全性確保と、「供給信頼度（停電リスク）」を評価するための新たな定量的手法の導入、さらに再エネ予測精度の向上について要点を整理します。

*   **阿南紀北直流幹線の油漏れ事故と安定供給への影響：**
    四国と関西を結ぶ重要な電力融通ルートである阿南紀北直流幹線にて発生した絶縁油の漏洩（内部障害）について、詳細な原因調査と復旧計画が共有されました。これは近畿・四国エリアの需給バランスを左右する重大事案であり、設備利用率向上に向けた運用の工夫が議論の焦点となっています。
*   **「供給不安」を数値化する新指標（EUE）の導入検討：**
    これまでの「予備率（％）」による評価から、不足する可能性のある電力量の合計を示す「EUE（Expected Unserved Energy：供給不足期待値）」による、より精密なリスク評価への移行準備が進められています。これにより、稀に発生する極端な気象条件や電源脱落のリスクを、より現実的に捉えた需給運用が可能になります。
*   **再エネ予測精度の限界と高度化に向けたアプローチ：**
    AIを活用した需要・供給予測の現状が報告されました。短周期の変動への対応力を高め、調整力のコスト（アンシラリーサービス費用）を抑制するための「予測誤差の最小化」が、電力システムの経済性維持に直結することを再確認しています。

### **主要な議題**

今回の委員会で議論された主要な議題は以下の通りです。

*   **阿南紀北直流幹線の漏油障害と運用対策：**
    障害設備の現状分析に基づき、復旧完了までの期間における運用容量の制約と、それを補うための他ルート（本四連系線等）の活用方法について。
*   **供給信頼度評価の課題整理（EUEと予備率の関係整理 その1）：**
    なぜ現在の予備率指標だけでは不十分なのか、EUEとの整合性をどう取るべきかという「供給信頼度評価の高度化」に向けた報告。
*   **再エネ予測精度向上に向けた取り組み：**
    各エリアの予測モデル（回帰分析、深層学習）の精度比較と、広域機関（OCCTO）による統合的な予測データの活用可能性について。

### **決定事項**

本会議の結果、以下の方向性が示されました。

*   **阿南紀北直流幹線の暫定運用方針の決定：**
    安全性第一を前提に、一部の極（ポール）を限定的に利用しつつ、詳細な内部点検を継続する並行運用のスケジュールが合意されました。
*   **EUE評価手法の精緻化プロセスの継続：**
    今回の報告（その1）に基づき、次回以降で具体的な「評価の閾値（クライテリア）」の策定を進めることが決定しました。
*   **予測データの広域共有プラットフォームの構築：**
    各送配電網事業者が個別に持っている予測情報を一元化し、より精度の高い予測値を全国で活用するための検討を加速させることが合意されました。

### **今後のタイムライン**

*   **2026年4月：** 
    阿南紀北直流幹線の本格的な復修作業のフェーズ移行。
*   **2026年夏季需給対策会合：** 
    今回の直流幹線トラブルを踏まえた、夏季のエリア間融通計画の最終確定。
*   **2026年後半：** 
    「供給信頼度評価の課題整理（その2）」としての、EUEを用いた具体的な評価モデルの提示。
*   **2027年度本格稼働：** 
    高度化された再エネ予測システムの導入と、調整力オークションでの予測データ活用開始。
