# 第15回 水素・アンモニア政策小委員会 カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）

1.  **世界的なコスト増大と「グリーン市場」の停滞懸念**
    インフレや化石燃料安による価格転嫁の壁、規制整備の遅れを背景に、欧州メジャーが化石燃料へ回帰している。この「グリーン市場の停滞」こそが、国内投資を維持するための制度拡充を促す戦略的トリガーとなった。

2.  **欧州における制度的強靭性と「底堅い」投資継続**
    市場全体が減速する中、欧州は安全保障の観点から英国CfD（11件採択）や欧州水素銀行（第2回：9.92億ユーロ）による巨額支援を継続。官民一体の長期的支援が、不透明な市場における投資の底堅さを支えている。

3.  **長期脱炭素電源オークションの抜本的拡充**
    第3回入札より燃料費が支援対象となり、上限価格は大幅に引き上げられた。燃料調達から発電に至るサプライチェーン全体を包括的に支援することで、事業者の予見可能性を抜本的に高め、投資決断を後押しする。

4.  **水素社会推進法と電源オークションの制度連結**
    電源オークションに「水素社会推進法」の予備審査を導入し、上流案件の確実性を担保する。チェックリスト方式による簡素化は、行政手続のボトルネックを解消し、迅速な商用化を促す規制緩和の一環である。

### 2. 主要な議題

1.  **電源オークションにおける事前審査のスキーム構築**
    第4回以降の入札から課される事前審査のフローが検討された。「水素社会推進法」に基づく予備審査の適合を入札要件とし、落札後に本審査・認定を行う。発電事業者が単独で申請可能な柔軟な枠組みとし、製造・輸送・売買契約案の審査を通じてサプライチェーン全体の政策意義を担保する。

2.  **日本産業の国際競争力強化に向けた要件設定**
    製造装置、輸送船舶、貯蔵設備、発電設備のうち、少なくとも1つで日本企業の競争力強化に寄与することを求める。また、国内製造能力の制約を考慮し、支出規模が大きく日本企業の強みを活かせる建設施工（EPC）についても評価対象に含めるべきとの議論がなされた。

3.  **上流事業の制御と安定供給の担保**
    日本企業による権益参入比率（出資比率）の確保を、安定供給および価格安定への「影響力」行使の手段として評価する。地政学的リスクへの対応や特定国への依存回避を基準に据えつつ、上流案件の確実性と、万一の際の退出ペナルティのバランスについても検討された。

4.  **トランプ政権下の米国政策の影響分析**
    米国の「OBBBA」法案により、CCS税額控除の継続が確認された。水素ハブへの資金拠出停止といった失速懸念はあるものの、2027年末までの建設開始で水素生産税額控除（PTC）の適用が可能であるため、2030年頃までのプロジェクトへの影響は限定的であるとの見方が示された。

### 3. 決定事項

1.  **脱炭素電源オークションの募集上限と価格設定**
    第3回入札における「脱炭素火力」の募集上限を50万kW（第2回における既設火力の半分）に設定。上限価格の平均は、従来の閾値20万円/kW/年の約2倍となる「40万円/kW/年」へと大幅に引き上げ、サプライチェーン全体のコストを反映させた。

2.  **グローバルな水素関連投資の実績と予測**
    2024年の投資実績は前年比60％増の「43億ドル」に到達した。2025年にはさらに加速し、必要な投資見込み額は前年比約2倍の「79億ドル」に達する見通しである。累計のコミット済み投資額は1,100億ドル（510案件）を突破した。

3.  **欧州における具体的な支援規模と落札案件**
    英国ラウンド1のCfD支援総額は「20.9億ポンド（約4,450億円）」、欧州水素銀行第2回入札の落札額は「9.92億ユーロ（約1,820億円）」となった。2025年時点での欧州の稼働済み水電解容量は「570MW超」を記録している。

4.  **海運規制「FuelEU Maritime」による削減目標**
    2025年1月より、5,000GT超の船舶を対象にGHG強度削減規制を開始する。2025年の「2.0%」から2050年の「80.0%」まで段階的に目標を強化し、不適合案件には「罰金（ペナルティ）」を科すことで規制の実効性を確保する。

2.  **2026年2月18日：** 第15回 水素・アンモニア政策小委員会の開催（本レポートの対象会議）。
