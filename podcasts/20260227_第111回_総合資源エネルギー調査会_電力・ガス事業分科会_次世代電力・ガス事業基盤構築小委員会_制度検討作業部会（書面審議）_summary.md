# カスタムレポート

### 1. ポッドキャスト解説ガイド（内容のポイント）
第111回電力およびガス基本政策小委員会では、カーボンニュートラルの実現に向けた投資環境の整備と電力供給の安定化を軸に、次期制度設計の詳細が議論されました。特に2024年度に実施される第2回長期脱炭素電源オークションの募集条件や、小売市場における健全な営業行為を確保するための規律強化、さらに2025年度から始まる第2期レベニューキャップ制度に向けた調整が焦点となっています。

* **総容量4.0GWの第2回長期脱炭素電源オークション**
脱炭素電源への投資を促すため、募集容量を合計4.0GWに設定し、そのうち蓄電池および揚水発電の優先枠として1.3GWを確保する方針が示されました。これにより、調整力の確保と脱炭素化の両立に向けた投資の予見性が大幅に向上します。

* **小売電気事業者による委託先管理の義務化**
媒介業者や取次業者による不適切な営業行為を抑止するため、委託元である小売電気事業者が実施すべき教育やモニタリング、苦情対応体制の整備をガイドラインに明記し、監督責任を厳格化する方向性が固まりました。

* **インバランス料金の算定パラメータの見直し**
需給逼迫時における適切な価格シグナルの発信と需要家への過度な負担軽減を両立させるため、インバランス料金の算定に用いるデルタ分や各種係数の調整について、市場の実態を反映した見直しが検討されました。

### 2. 主要な議題
* **長期脱炭素電源オークションの落札上限価格の設定**
蓄電池や既設電源の改修など、多様な電源の投資回収を確実にするため、標準的なプロジェクトコストを反映した上限価格の算定手法や、マルチイヤー契約の適用範囲が重要な議論のテーマとなりました。

* **小売営業における媒介および取次業者の規律強化**
販売現場でのトラブルを未然に防ぐため、小売電気事業者が代理店等に対して負うべき監督義務の範囲をどこまで拡大し、業務委託先での不適切事案をいかに根絶するかが論点として浮上しました。

* **第2期レベニューキャップ制度における効率化目標と投資評価**
2025年度からの次期規制期間において、送配電事業者がカーボンニュートラル関連投資を円滑に進めるための収入上限算定ルールや、物価変動などの外部要因を適切に反映する仕組みの構築が議論されました。

### 3. 決定事項
1. **第2回オークションの募集容量および電源区分の了承**
2024年度の募集容量を4.0GWとし、蓄電池および揚水発電に1.3GW、既設電源の改修や新規電源に2.7GWを割り当てる枠組みが決定されました。

2. **小売営業ガイドラインの改定による監督体制の強化**
小売電気事業者が委託先に対して定期的な教育およびモニタリングを行うことを義務付け、不適切な行為が発生した際の報告体制を整備する方針が合意されました。

3. **インバランス料金算定式における一部パラメータの調整**
市場の安定性を高めるため、供給不足時におけるインバランス料金の算定式に含まれるベータ係数や、需要家への影響を考慮したデルタ分の算定手法を調整し、市場参加者の予見性を確保することが決定されました。

### 4. 今後のタイムライン
1. **2024年度中の長期脱炭素電源オークション募集開始**
詳細な募集要綱を確定させた上で、2024年度内に応札の受付および落札者の選定を完了させるスケジュールで進行します。

2. **2024年度早期の改正小売営業ガイドライン施行**
パブリックコメントの結果を反映し、速やかに改正内容を公表することで、事業者側の体制整備期間を設けた上で同年度中に施行されます。

3. **2025年度の第2期レベニューキャップ制度の適用開始**
2024年度を通じて各一般送配電事業者の収入上限に関する審査および承認を完了させ、2025年4月からの新制度運用に繋げる予定です。
