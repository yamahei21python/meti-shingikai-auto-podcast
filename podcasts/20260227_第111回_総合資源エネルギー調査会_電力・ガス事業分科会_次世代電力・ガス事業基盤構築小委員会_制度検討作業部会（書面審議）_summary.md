# 第111回 制度検討作業部会（書面審議） カスタムレポート

本レポートは、第111回制度検討作業部会（書面審議）（111_01_00.pdf〜111_04_00.pdf）の審議内容に基づき、日本の電力システム改革の深化と、市場参加者が直面する実務的・戦略的課題をエネルギー政策アナリストの視点で構造化したものです。

### 1. ポッドキャスト解説ガイド（内容のポイント）

今回の小委員会では、カーボンニュートラル（CN）に向けた長期的な投資促進策と、足元の供給力不足を解消する安全網の構築、そして自由化市場における消費者保護の再定義という、極めて多層的な議論が行われました。

- **背景と技術的・政策的意義の要約**:
    - **脱炭素電源への投資回収の予見性確保**: 卸電力市場の価格変動リスクを抑え、多額の初期投資を要する脱炭素電源（水素・アンモニア混焼、原子力、蓄電池等）への投資を促すため、20年間にわたる固定費回収を保証する新たな市場枠組みが本格始動します。
    - **市場外での「戦略的予備力」の構築**: 火力電源の休廃止が加速する中、通常時には市場から退出している電源を、需給逼迫時のみ発動する「市場外予備力（電源I-b代替）」として確保する制度が具体化しました。
    - **小売市場の透明化と規律強化**: 市場連動型プランの普及に伴い、激しい価格変動による消費者トラブルを未然に防ぐため、リスクの「定量的な提示」や契約変更プロセスの厳格化が求められています。
    - **監視体制の強化**: 電力・ガス取引監視等委員会によるADR（紛争解決）事例の蓄積に基づき、不適切な勧誘や不当な解約違約金の設定に対する監視の目が一層厳しくなっています。

- **実務への影響分析**:
    - **発電事業者**: 長期脱炭素電源オークションにより、20年間の固定費回収が可能となる一方、卸市場価格が可変費を上回った場合にその超過分を還付する「収益還付メカニズム」が導入されます。収益のアップサイドが制限されるため、ファイナンス組成や応札戦略に直結します。
    - **小売電気事業者**: 改定される「小売営業指針」に基づき、市場連動プランのリスク説明として、過去の価格スパイク（2020年度冬季等）を反映した「定量的リスク提示」が義務付けられます。また、契約更新時と変更時の区別を明確にしたシステム・UI/UX改修が必要です。
    - **一般送配電事業者**: 戦略的予備力（電源I-b代替）の公募・管理実務が発生します。需給逼迫警報級の事態（予備率3%未満）での発動基準の運用など、実需給管理の難易度が高まります。

- **キーワード解説**:
    - **戦略的予備力**: 通常は市場から退出（休廃止予定）している電源を、一般送配電事業者が「市場外」で確保する仕組み。市場価格形成を歪めないよう、発動は需給逼迫時に限定されます。
    - **収益還付メカニズム**: 長期脱炭素電源オークションの落札者が、固定費の支払いを受ける見返りとして、市場で得た収益（可変費を除く）を還付する仕組み。国民負担の抑制と事業者の過剰収益防止を目的とします。
    - **定量的リスク提示**: 小売事業者が市場連動型プランを販売する際、単なる口頭説明ではなく、具体的な金額推計を用いて価格高騰リスクを示す義務です。

### 2. 主要な議題

- **議題の名称：戦略的予備力の具体的運用と「電源I-b代替」**
    - **現状の課題と論点**: 火力電源の休廃止が相次ぎ、厳冬・酷暑時の供給力が不足しています。これまでの「電源I（常時バックアップ）」では市場を歪める懸念があり、市場外で維持される予備力の新設が課題でした。
    - **提示された選択肢/アプローチ**: 休廃止予定の電源を対象に、公募により戦略的予備力を確保。発動条件は「予備率3%を下回る予測時」とし、発動価格は市場価格の上限等に設定することで市場への介入を最小限に抑えます。

- **議題の名称：長期脱炭素電源オークションの詳細設計（収益還付と期間）**
    - **現状の課題と論点**: 脱炭素投資には巨額の資金が必要ですが、市場価格の不確実性が投資の障壁となっています。
    - **提示された選択肢/アプローチ**: 原則20年間の支援期間を適用。蓄電池や揚水発電についても、投資回収期間の実態を踏まえ、一律で20年間の応札を可能とする方向が示されました。

- **議題の名称：小売営業指針の改定と市場連動型プランの適正化**
    - **現状の課題と論点**: 2020年度冬季の価格高騰時、市場連動型プランの契約者が高額な請求を受け、社会問題化しました。契約変更時の説明や合意形成プロセスが不十分なケースも散見されます。
    - **提示された選択肢/アプローチ**: 「契約更新（同一条件）」と「契約内容の変更（条件変更）」を明確に区別し、後者については原則として「積極的な合意（承諾）」を求める方針。また、リスク提示には具体的な過去の最高値を引用するよう義務化します。

- **対立軸と多様な視点**:
    - **国民負担 vs 供給安定性**: 戦略的予備力の維持費用は「託送料金」を通じて回収されるため、効率的な公募による費用抑制が求められています。
    - **ADR事例に基づく監視強化**: 電力・ガス取引監視等委員会からは、解約違約金が高額すぎる事例や、電話勧誘時の不適切な説明に対する指摘があり、ガイドラインへの反映と事後監視の徹底が強調されました。

### 3. 決定事項

- **合意事項の要約**:
    - **長期脱炭素電源オークションの本格始動**: 2023年度内に初回のオークションを実施することを決定。
    - **戦略的予備力の発動基準**: 需給逼迫警報級の事態（予備率3%未満）での発動を基本方針として承認。
    - **小売営業における「定量的なリスク提示」の義務化**: 市場価格高騰のリスクを消費者にイメージしやすく提示する方針で合意。

- **承認された基準・ルール（抜粋）**:

| 項目 | 具体的な内容・スペック | 根拠資料 |
| :--- | :--- | :--- |
| **オークション支援期間** | 全電源種（蓄電池・揚水含む）において**原則20年間** | 111_03_00 |
| **戦略的予備力の対象** | 市場から退出予定の**休廃止予定電源**（市場外での維持） | 111_01_00 |
| **戦略的予備力の発動基準** | 広域予備率**3%を下回る予測**が出た場合等 | 111_01_00 |
| **市場連動プランのリスク提示** | 2020年度冬季等の価格高騰実績を踏まえた**定量的な提示** | 111_02_00 |
| **契約変更時の通知** | 条件変更を伴う場合、書面等の交付と適切な説明を義務付け | 111_02_00 |

- **留保事項**:
    - 水素・アンモニア等の脱炭素燃料の定義（いわゆる低炭素の判定しきい値）の具体的詳細。
    - 2030年度以降の累積的な国民負担額（賦課金等）の推計精度と緩和策の検討。

### 4. 今後のタイムライン

- **マイルストーンの提示**:
    - **2023年度内**: 長期脱炭素電源オークションの初回入札実施および開札。
    - **2024年4月**: 改定後の「電力の小売営業に関する指針」の施行・本格運用。
    - **継続実施**: 電力・ガス取引監視等委員会による定期的なADR事例の公表と、それに基づく事業者への指導。

- **実務上の準備期間**:
    - **小売電気事業者**: 2024年4月の指針施行に向け、重要事項説明書の改訂、および市場連動リスクのシミュレーションツールの整備が必要です。特に「契約更新」と「条件変更」のプロセス分離は、基幹システムへの影響が大きいため、早期の改修着手が求められます。
    - **発電事業者**: 長期オークションへの参加にあたっては、20年間の収益還付が事業性に与える影響を精査し、応札価格を策定する必要があります。また、戦略的予備力を検討する休廃止予定電源保有者は、公募要領の公表に備えたコスト構造の整理が不可欠です。
